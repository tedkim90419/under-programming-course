Stream 개념

🌊Stream이란?

모든 입출력을 일련의 바이트 흐름으로 생각하고 처리하는 추상적 개념입니다. 입출력 장치의 물리적 차이를 감춰 주어 일관된 API로 다양한 장치를 다룰 수 있게 합니다.

  • 키보드, 디스플레이, 파일, 다른 프로그램 — 모두 스트림으로 통일
  • 입출력 버퍼링: 외부 장치 속도와 CPU 속도 차이를 메모리 버퍼로 완충

02

파일의 개념과 종류

📁파일(File)이란?

하드디스크 파일 시스템에 저장된 일련의 바이트 스트림입니다.

📄텍스트 파일 (Text File)

  • 사람이 읽을 수 있는 ASCII 코드 형태
  • 텍스트 에디터로 열람 가능
  • 라인 단위로 구분
  • 줄 끝 표현: Linux \n / Windows \r\n
예: C 소스코드, CSV, HTML, JSON…

🔢이진 파일 (Binary File)

  • 특정 이진 코드 형태로 인코딩된 파일
  • 텍스트 에디터로 읽으면 깨져 보임
  • 직접 실행하거나 전용 프로그램 필요
예: 실행 파일(.exe), 이미지(.png/.jpg), 오디오/비디오
⚠️
HWP, PPT, Word 문서는 텍스트 파일이 아닙니다! 텍스트처럼 보이지만 실제로는 이진 파일입니다. 텍스트 에디터로 열면 알아볼 수 없는 코드가 나옵니다.
03

파일 처리의 시작과 끝: fopen() / fclose()

🔑파일 입출력 3단계

① fopen()
→
② 읽기/쓰기
→
③ fclose()

fopen() — 파일 열기

fopen 프로토타입C
/* 헤더: stdio.h */
FILE * fopen(const char *pathname, const char *mode);
//          ↑ 파일 경로              ↑ 모드 문자열
// 성공: FILE 구조체 포인터 반환
// 실패: NULL 반환 (반드시 체크!)
fopen() 모드 탐색기 — 클릭해서 동작을 확인하세요
▶ 모드를 클릭해 동작을 확인하세요

fclose() — 파일 닫기

fclose 프로토타입C
int fclose(FILE *fp);
// 성공: 0 반환 / 실패: EOF(-1) 반환
// 버퍼에 남은 데이터를 파일에 flush 후 닫음
파일 I/O 기본 패턴
C
#include <stdio.h>
#include <stdlib.h>   // exit()

int main(void)
{
  FILE *ifp, *ofp;

  /* ① 파일 열기 */
  ifp = fopen("./my_file", "r");   // 읽기 모드
  if (ifp == NULL) {
    fprintf(stderr, "File open error\n");
    exit(1);
  }
  ofp = fopen("./outfile", "w");  // 쓰기 모드
  if (ofp == NULL) {
    fprintf(stderr, "File open error\n");
    exit(1);
  }

  /* ② 파일 읽기/쓰기 */
  // ... (fgetc, fgets, fscanf 등)

  /* ③ 파일 닫기 */
  fclose(ifp);
  fclose(ofp);
  return 0;
}
🚨
fopen() 반환값 NULL 체크는 필수! 잘못된 경로, 접근 권한 문제, 디스크 공간 부족 등으로 fopen()이 실패하면 NULL을 반환합니다. NULL 체크 없이 파일 연산을 수행하면 프로그램 크래시가 발생합니다.
04

문자 단위 입출력 — fgetc / fputc

📥fgetc() — 문자 읽기

int fgetc(FILE *fp);
// fp 파일에서 문자 하나를 읽어 반환
// 파일 끝(EOF)이면 EOF(-1) 반환
// 버퍼에서 한 글자씩 읽어 옴

📤fputc() — 문자 쓰기

int fputc(int c, FILE *fp);
// fp 파일에 문자 c 하나를 씀
// 일단 스트림 버퍼에 저장 후
// 조건 충족 시 실제 파일에 씀
💡
입출력 버퍼링 동작 읽기: 파일에서 버퍼 크기만큼 한 번에 읽어 두고, fgetc() 호출마다 버퍼에서 한 글자씩 꺼냄 (파일 접근 횟수 최소화).
쓰기: fputc()는 버퍼에 먼저 쌓고, 버퍼가 꽉 차거나 fclose()/fflush()/'\n' 출력 시 실제 파일에 씀.
fgetc로 파일 전체 읽기
C
FILE *fp;
int   ch;

if ((fp = fopen("a.txt", "r")) == NULL) {
  fprintf(stderr, "File open error\n");
  exit(1);
}
while ((ch = fgetc(fp)) != EOF)  // EOF까지 한 글자씩
  putchar(ch);                    // 화면에 출력
fclose(fp);
fgetc() 파일 읽기 시뮬레이터
파일 스트림 (file position indicator →)
▶ fgetc()를 호출해 한 글자씩 읽어보세요
05

라인 단위 입출력 — fgets / fputs

📥fgets() — 줄 읽기

char *fgets(char *buf, int n, FILE *fp);
// 최대 n-1개 문자를 읽어 buf에 저장
// 끝에 자동으로 '\0' 추가
// '\n' 문자도 buf에 포함됨
// EOF를 만나면 NULL 반환

📤fputs() — 줄 쓰기

int fputs(const char *buf, FILE *fp);
// buf의 문자열을 파일에 씀
// '\0'은 파일에 쓰지 않음
// 성공: 출력 문자 수 / 실패: EOF

🔍fgets() 동작 — c.txt 파일에서 3줄 읽기

c.txt 파일
We're \n
proud of\n
UOS MIE \n
→
fgets(str, 80, fp) 3회 호출
str ← "We're \n\0"
str ← "proud of\n\0"
str ← "UOS MIE \n\0"
fgets + fputs 파일 복사
C
FILE *ifp, *ofp;
char  buf[256];

ifp = fopen("src.txt",  "r");
ofp = fopen("dest.txt", "w");
/* NULL 체크 생략 (실제로는 필수!) */

/* fgets로 한 줄씩 읽어 fputs로 씀 */
while (fgets(buf, sizeof(buf), ifp) != NULL)
  fputs(buf, ofp);

fclose(ifp);
fclose(ofp);
⚠️
fgets()는 '\n'을 buf에 포함! fgets로 읽은 줄에는 줄바꿈 문자 '\n'이 그대로 포함됩니다. 필요 시 buf[strlen(buf)-1] = '\0'으로 제거하세요.
06

이진 파일 입출력 — fread / fwrite

🔢fread / fwrite — 블록 단위 입출력

구조체, 배열 등 다양한 형식으로 구조화된 데이터를 이진 파일에 읽고 쓸 때 사용합니다.

fread / fwrite 프로토타입
C
/* 읽기: fp 파일에서 count개 × size바이트 데이터를 ptr에 저장 */
size_t fread(void *ptr, size_t size, size_t count, FILE *fp);

/* 쓰기: ptr에서 count개 × size바이트 데이터를 fp 파일에 씀 */
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *fp);
// 반환값: 실제로 읽거나 쓴 데이터 개수 (바이트 아님!)
// EOF/에러 시: count보다 작은 값 반환 → feof()로 확인 필요
구조체 배열 이진 파일 저장/읽기
C
typedef struct { int id; char name[20]; double score; } Student;

/* 쓰기 */
Student students[3] = {{1,"Kim",95.5},{2,"Lee",87.0},{3,"Park",91.3}};
FILE *fp = fopen("students.bin", "wb");
fwrite(students, sizeof(Student), 3, fp);
// sizeof(Student)바이트씩 3개 씀
fclose(fp);

/* 읽기 */
Student buf[3];
fp = fopen("students.bin", "rb");
size_t n = fread(buf, sizeof(Student), 3, fp);
printf("읽은 개수: %zu\n", n);  // 3
fclose(fp);

📊fread/fwrite 파라미터 의미

fread( students, sizeof(Student), 3, fp);
↑ ptr: 저장 버퍼 ↑ size: 원소 크기 ↑ count: 개수 ↑ fp: 파일
07

형식 입출력 — fprintf / fscanf

📝fprintf / fscanf — 파일 버전의 printf / scanf

printf/scanf와 동일한 기능이지만 입출력 대상이 파일입니다.

fprintf / fscanf 프로토타입
C
int fprintf(FILE *fp, const char *format, …);
int fscanf (FILE *fp, const char *format, ...);

/* 표준 입출력과 동일 */
fprintf(stdout, ...)  == printf(...)
fscanf(stdin,  ...)  == scanf(...)

/* 에러 출력에는 stderr 사용 */
fprintf(stderr, "Error: %s\n", msg);
텍스트 파일에 데이터 쓰고 읽기
C
/* 쓰기 */
FILE *fp = fopen("data.txt", "w");
fprintf(fp, "%d %s %.2f\n", 1, "Kim", 95.5);
fprintf(fp, "%d %s %.2f\n", 2, "Lee", 87.0);
fclose(fp);
// data.txt: "1 Kim 95.50\n2 Lee 87.00\n"

/* 읽기 */
int id; char name[20]; double score;
fp = fopen("data.txt", "r");
while (fscanf(fp, "%d %s %lf", &id, name, &score) != EOF) {
  printf("id=%d name=%s score=%.1f\n", id, name, score);
}
fclose(fp);
id=1 name=Kim score=95.5
id=2 name=Lee score=87.0
⚠️
fscanf() 반환값 EOF 체크! fscanf()가 EOF(-1)을 반환하면 대부분 파일의 끝까지 읽었음을 의미합니다. 반환값을 확인해 루프를 종료해야 합니다.
08

파일 입출력 함수 요약 (stdio.h)

종류 함수 동작 설명 EOF/에러 반환
Text
File		 fgetc(fp) fp에서 문자 하나를 읽어 반환 EOF(-1)
fputc(c, fp) fp에 문자 c 하나를 씀 EOF(-1)
fgets(buf, n, fp) fp에서 최대 n-1개 문자를 읽어 buf에 저장 (라인 단위) NULL
fputs(buf, fp) buf의 문자열을 fp에 씀 EOF(-1)
※ fprintf(), fscanf() 도 텍스트 파일 대상 (형식화된 구조 데이터에 편리)
Binary
File		 fread(ptr, size, count, fp) fp에서 count개 × size바이트를 읽어 ptr에 저장 count보다 작은 값
fwrite(ptr, size, count, fp) ptr에서 count개 × size바이트를 fp에 씀 count보다 작은 값
📌
각 파일 스트림은 file position indicator(현재 읽기/쓰기 위치)를 유지합니다. 입출력 함수를 호출할 때마다 읽거나 쓴 바이트만큼 자동으로 이동합니다.
09

기타 파일 처리 함수 (stdio.h)

fseek() — file position indicator 이동 시뮬레이터
파일 내용: "Hello, World!" (13 bytes)
file position: 0
▶ fseek()를 실행해보세요
함수프로토타입동작
fseek int fseek(FILE *fp, long offset, int origin) file position indicator를 origin 기준으로 offset 바이트 이동
origin: SEEK_SET(0)=시작, SEEK_CUR(1)=현재, SEEK_END(2)=끝
ftell long ftell(FILE *fp) 현재 file position indicator 값 반환 (실패 시 -1)
rewind void rewind(FILE *fp) file position을 파일 맨 앞으로 이동
= fseek(fp, 0L, SEEK_SET)
feof int feof(FILE *fp) 현재 position이 파일 끝인지 검사 (끝이면 0이 아닌 값)
fflush int fflush(FILE *fp) 출력 버퍼 내용을 즉시 파일에 씀 (0: 성공, EOF: 실패)
remove int remove(const char *pathname) 파일 삭제
tmpfile FILE *tmpfile(void) 임시 이진 파일 생성·오픈 (프로그램 종료 시 자동 삭제)

파일 입출력 개념을 확인해봅시다. 클릭하여 정답을 확인하세요!

QUIZ 01 / 06
기존 파일이 존재할 때 fopen("data.txt", "w")를 호출하면?
A NULL을 반환하며 실패한다.
B 기존 내용이 삭제되고 새 파일로 열린다.
C 기존 내용 뒤에 이어서 쓸 수 있도록 열린다.
D 읽기 전용으로 열린다.
✅ 정답: B
"w" 모드는 파일이 이미 존재하면 기존 내용을 모두 삭제(덮어쓰기)하고 처음부터 씁니다.
파일이 없으면 새로 생성합니다. 기존 내용을 보존하려면 "a"(append) 모드를 사용하세요.
QUIZ 02 / 06
다음 중 파일에서 데이터를 읽을 때 틀린 설명은?
A fgetc()는 파일 끝을 만나면 EOF(-1)를 반환한다.
B fgets()는 읽은 줄에 '\n' 문자를 포함시킨다.
C fgets()는 파일 끝을 만나면 EOF(-1)를 반환한다.
D fscanf()가 EOF를 반환하면 파일을 다 읽은 것이다.
✅ 정답: C
fgets()는 파일 끝을 만나면 NULL을 반환합니다 (EOF가 아닙니다!).
fgetc()는 EOF(-1)를 반환하고, fgets()는 NULL을 반환한다는 차이를 기억하세요.
QUIZ 03 / 06
fread(buf, sizeof(Student), 5, fp)가 3을 반환했다면 의미는?
A 3 바이트를 읽었다.
B Student 구조체를 3개 읽었다. (파일에 5개가 없었음)
C 오류가 발생했다.
D 파일이 정상적으로 3개 남아 있다는 뜻이다.
✅ 정답: B
fread()의 반환값은 실제로 읽은 데이터 개수(바이트가 아닌 항목 수)입니다.
요청한 5개보다 작은 3이 반환됐으므로, 파일에서 Student 구조체를 3개만 읽었습니다. 파일 끝(EOF)이나 에러가 발생한 것입니다. 정확한 확인은 feof()로 합니다.
QUIZ 04 / 06
파일 크기가 100바이트인 파일에서 fseek(fp, -10, SEEK_END) 후 ftell(fp)의 반환값은?
A -10
B 90
C 100
D 10
✅ 정답: B — 90
SEEK_END는 파일 끝(위치 100)을 기준으로 합니다.
offset이 -10이므로: 100 + (-10) = 90번째 바이트 위치로 이동합니다.
ftell()은 현재 file position indicator 값(90)을 반환합니다.
QUIZ 05 / 06
구조체 배열을 파일에 저장하고 다시 읽을 때 가장 적합한 함수 조합은?
A fgets / fputs ("r", "w" 모드)
B fscanf / fprintf ("r", "w" 모드)
C fread / fwrite ("rb", "wb" 모드)
D fgetc / fputc ("r", "w" 모드)
✅ 정답: C — fread / fwrite
구조체 배열처럼 정해진 크기의 이진 데이터를 그대로 저장/복원할 때는 fread()/fwrite()가 가장 적합합니다.
이진 모드("rb", "wb")로 열어야 OS별 줄바꿈 변환 없이 정확하게 처리됩니다.
QUIZ 06 / 06
fputc()로 문자를 출력했는데 파일에 즉시 반영되지 않는 이유는?
A fputc()에 버그가 있어서
B fopen()을 잘못 호출했기 때문에
C 출력 스트림 버퍼에 먼저 저장되기 때문에
D fclose()를 이미 호출했기 때문에

버퍼가 꽉 차거나, fclose()/fflush() 호출 또는 '\n' 출력 시에 실제 파일에 씌어집니다. 즉시 반영하려면 fflush(fp)를 호출하세요.
