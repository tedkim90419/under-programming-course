01

프로그래밍 개념

📄 소스 코드 (Source Code)

프로그래밍 언어 문법에 따라 컴퓨터의 동작을 서술한 텍스트 문서 (작업 지시)

  • 사람이 읽고 이해할 수 있는 형태
  • 직접 실행 불가 → 변환 필요

⚙️ 이진 실행 프로그램

하드웨어에서 직접 실행을 위해 기계(CPU) 의존적인 2진 코드(instruction)를 모아 둔 것

  • 소스 코드 → 번역(컴파일) → 실행 파일
  • CPU 아키텍처마다 다른 기계어 코드 생성

🔢 소스 코드 → 기계어 변환 예시

int i, j, k;    →    i = j + k;

MIPS 32-bit
add $t0, $s2, $s3
→ 000000 10001 10010 01000 00000 100000
ARM 32-bit
add r0, r1, r2
→ 1101 00 0 0100 0 0001 0000 000000000010
💡
같은 소스 코드라도 CPU 아키텍처마다 다른 기계어로 번역됩니다. 이것이 Low-level language (어셈블리)가 Hardware-dependent한 이유입니다.

Low-level Language

  • 기계어 (Machine language)
  • 어셈블리 언어 (Assembly)
  • Hardware-dependent
  • CPU 마다 문법이 달라짐

High-level Language

  • Python, C, C++, C#, Java 등
  • Hardware-independent
  • 작성/수정 시간이 짧음
  • 이식성 (Portability) 높음

🔄 프로그램 변환 과정

High-level language로 작성된 소스 코드는 실행을 위해 이진 기계어 코드로 변환(번역)되어야 함

C 프로그래밍 언어

📜 역사

  • Bell lab.의 Dennis Ritchie가 제안 (1972)
  • ALGOL 60(1960) → CPL(1963) → BCPL(1969) → B language(1970)
  • C 표준: ANSI C (C89), C90, C99, C11, C17, C23
  • 컴파일러 종류에 따른 문법 차이 해소
  • UNIX 운영체제 개발에 활용 → 검증된 프로그래밍 언어
  • 전문가용 언어로 시작 → 컴퓨터 구조에 대한 이해

⭐ C 언어의 특징

  • 간결함 (Simple) — 비교적 단순한 문법, 꼭 필요한 기능만
  • 하위 수준 제어 (Low-level control) — 하드웨어 직접 제어 가능
  • 효율적 (Efficient) — 실행 프로그램 크기가 작고, 실행 속도 빠름
  • 높은 이식성 (High portability) — 다양한 시스템 환경에 쉽게 이식
🔌
임베디드 시스템
CPU, 메모리 등 자원이 제한적인 임베디드 시스템에 적합
⚡
고성능 응용
높은 성능을 요구하는 응용 분야에서 필수
🌐
범용성
다양한 언어에 적응이 쉽고 효율적으로 이용 가능

Comments (주석) & Indentation (들여쓰기)

💬 Comments (주석)

/* 와 */로 묶여진 임의의 문자열로 코드의 내용을 설명하는 부분

  • 컴파일러는 comment 부분 전체를 하나의 공백 문자로 대치 (번역하지 않음)
  • 프로그램 코드가 하는 일에 대한 설명과 코드의 정확성 검증을 위해 필수적인 문서화 도구
✅ 올바른 주석 스타일

 *****************************/

// C++ 스타일 한 줄 주석

주석 중첩 금지!/* */ 주석은 중첩해서 사용할 수 없습니다. 내부에 또 다른 /*를 쓰면 예상치 못한 동작이 발생합니다.

↔️ Indentation (들여쓰기)

같은 수준에 있는 문장들에 대해 왼쪽 여백을 줘서 들여 쓸 필요가 있음

Programming Style Tip — 소스 코드의 가독성 향상 들여쓰기를 하지 않더라도 컴파일에 문제는 없지만, 소스 코드가 어떤 구조로 되어 있는지를 알아 볼 수 없음. 특히 소스 코드의 길이가 길어질수록 적절한 들여쓰기는 필수! 일반적으로 Tab 키를 이용 (VSCode: Ctrl + ])

Preprocessor (전처리기)

⚙️ 전처리기란?

C 언어는 기본 문법에서 제공하는 틀 외에 전처리기(preprocessor)를 사용하여 다양한 외부 함수 활용을 편하게 하고 소스 코드 표현법을 확장함.

소스파일
.c
#include, #define...
→
전처리기
만 처리합니다
→
C 컴파일러
나머지는 나 한테 맡겨
→
오브젝트
파일
.o / .obj
📌
'#' 으로 시작하는 라인을 전처리기 지시어 (preprocessing directive)라고 함.
대표적인 예: #include 구문, #define 구문
hello.c — #include 동작 방식
C 
#include <stdio.h>   /* 헤더 파일 포함 (컴파일 전에 전처리기가 확장) */

int main(void)
{
    printf("Hello World!");  /* stdio.h 에 선언된 함수 사용 */
    return 0;
}
💡
#include <stdio.h>를 쓰면 전처리기가 컴파일 전에 stdio.h 헤더 파일의 내용(예: int printf(char *, ...);)을 소스 파일에 삽입합니다.
06

Function (함수)

🧱 Top-down Programming (하향식 프로그래밍)

  • 주어진 문제를 관리가 용이한 작은 부분으로 쪼개어 설계하는 방식
  • 함수의 활용은 전형적인 하향식 설계/구현 방법임
  • C 언어로 작성된 프로그램은 반드시 하나 이상의 함수로 구성됨
  • 프로그램 실행의 출발점인 main() 함수는 꼭 있어야 함
  • → 함수는 프로그램의 기본 building block

✅ 함수 사용의 이점

  • 중복되는 코드 방지 → 간결한 코드 (가독성)
  • 코드 재사용 → 프로그래머의 코딩 부담 감소
  • 모듈화된 설계 → 개발과정과 유지보수 비용 감소

📦 함수의 종류

  • 라이브러리 함수 (Library functions)
    → printf, scanf, sqrt 등 표준 제공
  • 사용자 정의 함수 (User-defined functions)
    → 프로그래머가 직접 작성

🔍 함수 구조 — Header + Body

function_structure.c
C
return_type function_name( parameter_list )   /* ← Header */
{
    /* 변수 선언 */
    variable_declarations;

    /* 명령문들 */                                  /* ← Body */
    statements;

    return ...;    /* 실행 결과 반환문 */
}
HEADER 구성
  • return_type — 실행 결과 데이터의 타입
  • function_name — 식별자 규칙을 따름
  • parameter_list — 외부에서 받는 입력값
BODY 구성
  • {와 }로 둘러싸인 부분
  • 변수 선언 + 실행할 명령문들
  • return문으로 결과값 반환 가능

Variables (변수) & Identifier (식별자)

📦 Variables (변수)

  • 특정 데이터를 저장하고 있는 메모리 공간의 위치(주소)를 친숙한 심볼(이름)로 표현
  • 특정한 식별자 규칙(identifier rule)에 따라 이름을 정함
  • 각 변수는 특정한 데이터 타입(data type)을 가짐
  • 변수는 사용하기 전에 꼭 선언(declare) 되어야 함
  • 선언: 변수의 데이터 타입과 이름을 명시하는 작업
  • 선언과 함께, 값을 초기화(initialize) 하는 것이 바람직함

🏷️ Identifier (식별자) 생성 규칙

identifier ::= {letter | underscore}1{letter | underscore | digit}0+
  • 꼭 문자나 밑줄('_') 기호로 시작하고, 영문자, 숫자, 또는 밑줄 기호로 구성해야 함
  • C 언어에서는 소문자와 대문자로 구성된 식별자는 서로 다른 이름 (abc ≠ ABC)
  • 한 프로그램 내에서 서로 다른 객체를 가리키는 식별자는 같으면 안 됨 (unique)
  • C 언어 자체에서 정의한 keyword들과 동일한 식별자는 사용 금지

08

수식과 연산 & 입출력 함수

🔢 Expressions and Operations (수식과 연산)

주어진 수식 (Expression)을 계산하여 결과를 얻어내는 과정을 연산이라고 함

OPERATOR (연산자)
실행할 연산을 나타내는 기호
예: +, -, *, /, >, ==
OPERAND (피연산자)
연산 대상이 되는 데이터 값
예: a, b, x, 10, 3.14
a = a + b;    // a+b 는 Expression, + 는 Operator, a와 b는 Operand
if (i > 10)   // i>10 은 Expression, 결과는 참(1) 또는 거짓(0)
while (x == y) // x==y 는 Expression, 수식의 결과로 항상 값이 결정됨
💡
많은 경우, C 소스 코드의 실행문 (statements)은 수식을 활용한 연산 결과를 변수에 저장하는 형태임. 수식 실행 결과로는 항상 구체적인 값(value)이 결정됨.

🖨️ 출력함수 printf() 활용

화면 출력을 위한 표준 라이브러리 함수

📋
사용법: printf("출력 형식 지정", 출력 대상);
• 문자열 출력: 출력 대상 생략 가능 → printf("Hello World!");
• 상수 값과 변수 값 출력: 형식 지정자(format specifier) 사용
형식 지정자의미출력 대상예시
%d정수 형태로 출력정수형 상수, 정수 타입 변수printf("%d", 42)
%f실수 형태로 출력실수형 상수, 실수 타입 변수printf("%f", 3.14)
%lfdouble 실수 출력double 타입 변수printf("%lf", d)
%c문자 형태로 출력문자형 상수, 문자 타입 변수printf("%c", 'A')
%s문자열 형태로 출력문자열 상수, 문자 배열printf("%s", str)
printf_example.c
C
int number = 7;
float grade = 4.5;

printf("번호: %d, 평균점수: %f", number, grade);
번호: 7, 평균점수: 4.500000

⌨️ 입력함수 scanf() 활용

키보드에서 사용자 입력을 받기 위한 표준 라이브러리 함수

⚠️
주의! 대부분의 경우, 변수명을 쓸 때 앞에 '&' 기호를 붙여 주소임을 명시해야 합니다. (예외: 문자열 배열은 & 불필요)
scanf_example.c
C
int number;
float grade;

scanf("%d %f", &number, &grade);
/*         ↑      ↑  → & 기호로 변수의 주소를 전달 */
형식 지정자의미예시
%d정수를 10진수로 입력scanf("%d", &i);
%ffloat 타입 실수로 입력scanf("%f", &f);
%lfdouble 타입 실수로 입력scanf("%lf", &d);
%c문자 형태로 입력scanf("%c", &ch);
%s문자열로 입력scanf("%s", s);

✅ 정답: ④ 객체지향성
C는 절차지향(procedural) 언어입니다. 객체지향 언어는 C++, Java, Python 등이 해당됩니다. C 언어의 주요 특징은 간결함(Simple), 하위 수준 제어(Low-level control), 효율성(Efficient), 높은 이식성(High portability)입니다.
Q 02 · 단일 선택
다음 중 주석(comment)에 대한 설명 중 잘못된 것은?
① 주석은 프로그램에 대한 설명에 해당하는 내용이다.
② 주석 처리(comment out)된 코드도 실제로 번역하고 실행한다.
③ /* 와 */ 로 된 주석은 중첩해서 사용할 수 없다.
④ 주석의 시작 부분에는 /* 기호를, 주석의 끝 부분에는 */ 기호를 써 준다.
✅ 정답: ②
컴파일러는 주석(comment) 부분 전체를 하나의 공백 문자로 대치합니다. 즉, 주석은 번역(컴파일)되지 않고 실행되지도 않습니다. 주석은 순수하게 코드 설명을 위한 문서화 도구입니다.
Q 03 · 단일 선택
변수명이나 함수명과 같은 식별자를 만들기 위한 규칙 중 잘못된 것을 고르시오.
① 식별자는 반드시 영문자, 숫자, 밑줄 기호 ('_') 만을 사용해야 한다.
② char, for, const 같은 C 언어의 키워드(keyword)는 식별자로 사용할 수 없다.
③ 식별자는 대소문자를 구분하지 않는다.
④ 식별자의 첫 글자는 반드시 영문자나 밑줄기호로 시작해야 한다.
✅ 정답: ③
C 언어에서는 식별자의 대소문자를 구분합니다 (case-sensitive). 예: abc와 ABC는 서로 다른 식별자입니다. Python, Java, C 모두 대소문자를 구분합니다.

Q 05 · 단일 선택
C 언어의 수식과 연산에 대한 설명 중 잘못된 것은?
① 연산자(operator)는 연산에 사용되는 기호이다.
② 연산의 대상이 되는 값을 피연산자(operand)라고 한다.
③ 연산자를 사용하는 수식의 결과로 항상 값이 결정된다.
④ 프로그래머가 직접 연산자를 만들어서 사용할 수 있다.
✅ 정답: ④
C 언어에서 연산자는 언어에서 미리 정의된 것만 사용할 수 있습니다. 프로그래머가 직접 새로운 연산자를 정의할 수 없습니다. (C++에서는 연산자 오버로딩이 가능하지만 C는 불가)
Q 06 · 복수 선택
C 프로그램의 입출력에 대한 설명 중 잘못된 것을 모두 고르시오.
① C 프로그램마다 입출력을 위한 함수를 매번 직접 만들어서 사용해야 한다.
② 입출력 라이브러리 함수를 사용하기 위해서는 stdio.h 라는 헤더 파일을 포함해야 한다.
③ 콘솔 화면에 출력을 위해 사용되는 함수는 printf 함수이다.
④ 콘솔로부터 사용자 입력을 받는 데 사용되는 함수는 scanf 함수이다.
⑤ printf 함수는 변수 값은 출력할 수 없고 정해진 문자열만 출력할 수 있다.
✅ 정답: ①, ⑤

① 오답: printf, scanf는 표준 라이브러리 함수이므로 직접 만들 필요 없이 #include <stdio.h>만 하면 사용 가능합니다.
⑤ 오답: printf는 형식 지정자(%d, %f, %s 등)를 사용하여 변수 값도 출력할 수 있습니다.

int main(void)
{
    int   a;
    float b;
    scanf(, &a, &b);
