Part 1 — 구조체 (Structure)
01

C 언어 데이터 타입 전체 구조

🗺️C 데이터 타입 분류

Fundamental (기본형)
char, short, int, long
float, double, …
Derived (파생형)
pointer, array
structure, union
User-defined (사용자 정의형)
typedef, enum

💡배열 vs 구조체

배열 (Array)

동일한 데이터 타입 여러 개를 하나의 이름으로 묶음

int grades[5]; // int 5개
구조체 (Structure)

서로 다른 데이터 타입 여러 개를 하나의 새로운 타입으로 정의

struct student {
  int    number;
  char   name[10];
  double grade;
};
02

typedef — 사용자 정의 타입 이름

🏷️typedef란?

기존 자료형에 새로운 이름(별칭)을 붙이는 키워드입니다. 코드 가독성을 높이고 이식성을 개선합니다.

typedef 기본 사용법
C
/* 기본 형식 */
typedef primitive_type user_defined_name;

/* 예시 */
typedef unsigned char  BYTE;    // BYTE = 1 byte unsigned
typedef int            INT32;   // INT32 = 4 byte int
typedef short          INT16;   // INT16 = 2 byte short

/* 이제 아래처럼 사용 가능 */
BYTE  index;
INT32 i;
INT16 s;

✅typedef 장점

  • 타입 이름을 용도에 맞게 친숙하게 변경
  • 플랫폼 간 이식 시 한 곳만 수정하면 됨
  • 구조체 타입 선언을 간결하게 사용 가능

🔗구조체와 typedef 조합

// struct student 선언 후 typedef
typedef struct student Student;

// 또는 한 번에!
typedef struct {
  int number;
  char name[10];
} Student;

Student s1, s2; // struct 생략 가능
03

구조체 정의 (Structure Definition)

구조체 문법 해부 — 각 부분에 마우스를 올려보세요
struct student {
int number ; // member variable 1
char name[10] ; // member variable 2 (배열도 가능)
double grade ; // member variable 3
}; // ← 세미콜론 필수!
⚠️
구조체 타입 정의 ≠ 변수 선언! 위 선언은 타입의 구조(청사진)만 정의한 것입니다. 실제 메모리를 차지하는 변수 선언은 별도로 해야 합니다.

구조체 타입 정의 + 변수 선언 4가지 패턴

①타입 정의 → 변수 선언 (분리)

struct student { /* 구조체 타입 정의 */
  int number; char name[10]; double grade;
};
struct student s1, s2; /* 변수 선언 */

가장 일반적인 방법. 타입 재사용이 쉬움.

②타입 정의 + 변수 선언 동시에

struct student {
  int number; char name[10]; double grade;
} s1, s2; /* 정의와 동시에 변수 선언 */

타입 정의와 변수 선언을 한 번에.

③typedef로 새 타입 이름 부여 (권장)

/* 방법 A: 별도 typedef */
struct student { int number; char name[10]; double grade; };
typedef struct student Student;
Student s1, s2;

/* 방법 B: 한 번에 (태그 이름 생략 가능) */
typedef struct {
  int number; char name[10]; double grade;
} Student;
Student s1, s2; // struct 키워드 불필요!

④익명(태그 없는) 구조체

struct { /* 태그 이름 없음 */
  int number; char name[10]; double grade;
} s1, s2;
// ⚠️ 나중에 추가 변수 선언 불가!
//    이름이 없으므로 타입을 다시 참조할 방법이 없음

추가 변수 선언이 불가하므로 사용 범위가 제한됨.

04

구조체 변수 선언 & 초기화

🔧초기화 방법

중괄호 {}로 감싸고, 각 멤버 초기값을 정의된 순서대로 쉼표로 구분합니다.

구조체 초기화 예시
C
/* 기본 초기화 */
struct card { int pips; char suit; };
struct card c = {13, 'h'};   // king of hearts

/* 선언과 동시에 초기화 */
struct home_address {
  char *street;
  char *city_and_state;
  long  zip_code;
} address = { "87 West Street", "Aspen, Colorado", 80526 };

/* {0}으로 전체 0 초기화 */
struct home_address prev = {0};

/* 구조체 배열 + 2D 초기화 */
typedef struct { double real; double imag; } Complex;
Complex a[3][3] = {
  {{1.0, -0.1}, {2.0, 0.2}, {3.0, 0.3}},
  {{4.0, -0.4}, {5.0, 0.5}, {6.0, 0.6}},
  // a[2][0..2] → 자동으로 0
};

05

멤버 접근 연산자 ( . ) 와 ( -> )

🔵. — 직접 접근 (구조체 변수)

구조체 변수를 통해 멤버에 직접 접근합니다.

struct card c1;
c1.pips = 3;     // 쓰기
c1.suit = 's';
int x = c1.pips; // 읽기
사용법: 구조체변수명.멤버변수명

🟠-> — 간접 접근 (포인터)

구조체를 가리키는 포인터를 통해 멤버에 접근합니다.

struct card c1;
struct card *pcard = &c1;
pcard->pips = 1;    // ✅
(*pcard).pips = 2; // ✅ 동일
*pcard.pips = 3;   // ❌ 에러!
사용법: 포인터변수->멤버변수명
🚨
*pcard.pips는 컴파일 에러! .과 ->는 최고 우선순위(좌→우 결합)이므로, *pcard.pips는 *(pcard.pips)로 해석됩니다. pcard는 포인터이지 구조체가 아니므로 .을 사용할 수 없습니다.
→ 포인터에 .을 쓰려면 반드시 괄호: (*pcard).pips

📊멤버 접근 표현식 예시 테이블

struct student s1; struct student *p = &s1; — s1.last_name="Kim", s1.student_id=910017, s1.grade='A'

수식동일 표현값
s1.gradep->grade'A'
s1.last_namep->last_name"Kim"
(*p).student_idp->student_id910017
*p->last_name + 1(*(p->last_name)) + 1'L' ('K'+1)
*(p->last_name + 2)(p->last_name)[2]'m'
. vs -> 연산자 선택 트레이너
06

구조체 변수에 허용되는 연산

✅가능한 연산

  • = 대입 연산자 (같은 타입 간 멤버 전체 복사)
  • & 주소 연산자
  • * 역참조 연산자
  • sizeof 크기 연산자
  • 멤버 변수 간 산술/관계/등가/논리 연산

❌불가능한 연산

  • == 구조체 변수 직접 비교 불가
  • +, -, *, / 구조체 변수 간 직접 산술 불가

→ 멤버 변수 각각에 적용해야 합니다.

Point 구조체 연산 예시
C
typedef struct { int x; int y; } Point;

Point p1 = {10, 20};
Point p2 = {30, 40};
Point p3;

/* ✅ 대입 — 멤버 전체 복사 */
p2 = p1; // p2.x=10, p2.y=20

/* ❌ 직접 비교 불가 → 멤버별로 */
if (p1 == p2) ...   // ❌
if ((p1.x==p2.x) && (p1.y==p2.y)) ... // ✅

/* ❌ 직접 산술 불가 → 멤버별로 */
p3 = p2 - p1;        // ❌
p3.x = p2.x - p1.x;  // ✅
p3.y = p2.y - p1.y;  // ✅

구조체 배열

📚구조체 배열

구조체 타입의 배열을 선언하면 각 원소가 구조체 변수입니다. student[i].name처럼 인덱스와 멤버 접근 연산자를 함께 사용합니다.

구조체 배열 — 학생 정보 입력
C
#include <stdio.h>
#define CLASS_SIZE 3

typedef struct {
  char name[20];
  int  id;
  char grade;
} Student_info;

int main(void)
{
  int i;
  Student_info student[CLASS_SIZE] = { 0 }; // 전체 0 초기화

  for (i = 0; i < CLASS_SIZE; i++) {
    printf("Input student %d info: ", i);
    // student[i].name → 배열 + 구조체 멤버
    scanf("%s %d %c",
      student[i].name,
      &student[i].id,
      &student[i].grade);
  }
  return 0;
}

🗃️구조체 배열 메모리 레이아웃 — Student_info student[3]

각 원소가 구조체 하나 (name[20]=20B + id=4B + grade=1B + padding=3B = 28B)

중첩 구조체 (Nested Structure)

🔗구조체 안에 구조체

구조체의 멤버 변수로 또 다른 구조체 타입을 사용할 수 있습니다. 반드시 안쪽 구조체 타입이 먼저 선언되어야 합니다.

Employee 중첩 구조체 예시
C
struct dept {
  int   dept_no;
  char *dept_name;
};

typedef struct {
  char            name[20];
  int             employee_id;
  struct dept     department;   // 구조체 멤버!
  struct home_addr *addr;       // 포인터 멤버 (불완전 타입 OK)
} Employee_data;

Employee_data e;

/* 중첩 멤버 접근: . 두 번 사용 */
e.department.dept_no   = 1002;   // ①e의 department, ②dept_no
e.department.dept_name = "CS";
Employee_data e 구조체 메모리

employee_id
struct dept
dept_no
dept_name*
addr*
접근: e.department.dept_no
09

구조체와 함수

📞구조체를 함수 인자로 전달

구조체 변수를 함수 인자로 전달하면 Call-by-Value — 전체 구조체의 지역 사본이 생성됩니다. 멤버에 배열이 있으면 그 배열도 복사됩니다.

⚠️
구조체가 크면 복사 오버헤드 발생! 멤버가 많거나 크기가 큰 배열 멤버가 있을 때, 매번 복사하는 것은 매우 비효율적입니다.
→ 프로그래밍 팁: 구조체 포인터(주소)를 전달하는 것이 바람직합니다 (Call-by-Reference)!

📋값으로 전달 (비효율)

/* 구조체 통째로 복사 */
Employee_data update(Employee_data e)
{
  int n;
  scanf("%d", &n);
  e.department.dept_no = n;
  return e; // 다시 복사해서 반환
}
// 호출
Employee_data e;
e = update(e); // 복사 2번!

✅포인터로 전달 (효율, 권장)

/* 포인터만 전달 — 복사 없음! */
void update(Employee_data *pe)
{
  int n;
  scanf("%d", &n);
  pe->department.dept_no = n; // -> 사용
  return;
}
// 호출
Employee_data e;
update(&e); // 주소만 전달!
🔒
읽기 전용 구조체는 const 포인터 사용 (Secure Coding) 구조체의 내용을 읽기만 할 경우, 매개변수에 const 키워드를 사용하세요:
void display(const Employee_data *pe) — 실수로 내용을 수정하는 것을 컴파일러가 방지합니다.

공용체 (Union)

🔀공용체란?

구조체와 비슷한 선언 형식이지만, 모든 멤버 변수가 동일한 메모리 공간을 공유합니다.

  • 한 순간에는 하나의 멤버로만 유효한 값을 가짐
  • 메모리 크기 = 가장 큰 멤버의 크기
  • 같은 메모리 위치를 다르게 해석할 때 유용
  • 올바른 해석은 프로그래머의 책임!

📦struct (독립 공간)

최소 12~16 Bytes
int i
4B
double d
8B
struct int_or_float {
  int    i;
  double d;
}; // 12~16 bytes

🔀union (공유 공간)

8 Bytes (double 크기)
i / d 공유
union int_or_double {
  int    i;
  double d;
}; // 8 bytes만!
union 동작 예시 — 같은 공간 다르게 해석
C
union int_or_double { int i; double d; };
union int_or_double u;

u.i = 4444;
printf("i: %d  d: %e\n", u.i, u.d);
// i: 4444  d: 2.1956e-320  ← d는 의미 없음!

u.d = 4444.0;
printf("i: %d  d: %e\n", u.i, u.d);
// i: 0  d: 4.4440e+03  ← i는 의미 없음!
// 마지막에 저장한 멤버만 올바름!
i: 4444 d: 2.1956277301e-320
i: 0 d: 4.4440000000e+03
🚨
union 초기화 주의! union id var = {"Tom", 1};처럼 멤버 개수보다 많은 초기값을 주면 컴파일 경고가 발생합니다. union은 첫 번째 멤버 하나만 초기화할 수 있습니다.
11

열거형 (Enumeration Type)

🎨열거형이란?

정수형 상수에 의미 있는 이름을 붙여 집합으로 정의하는 타입입니다. 코드 가독성과 유지보수성을 높입니다.

  • 기본값: 첫 열거자는 0부터 시작, 이후 1씩 증가
  • 특정 열거자에 다른 시작값 지정 가능
  • 정수형 상수만 할당 가능 (문자열, 실수 불가)
열거형 상수값 탐색기
열거형 선언과 변수 사용
C
/* 열거형 타입 정의 */
enum day { Sun, Mon, Tue, Wed, Thu, Fri, Sat };

/* 변수 선언 */
enum day d1, d2;
d1 = Fri;

/* typedef와 결합 (권장) */
typedef enum day Day;
Day today = Mon;

/* 또는 한 번에 */
typedef enum { Sun, Mon, Tue, Wed, Thu, Fri, Sat } day;

/* 비교 연산 가능 */
if (d1 == d2) { /* do something */ }
열거형 활용 — find_next_day()
C
typedef enum { sun, mon, tue, wed, thu, fri, sat } day;

day find_next_day(day d) {
  day next;
  switch(d) {
    case sun: next = mon; break;
    case mon: next = tue; break;
    case tue: next = wed; break;
    case wed: next = thu; break;
    case thu: next = fri; break;
    case fri: next = sat; break;
    case sat: next = sun; break;
  }
  return next;
}

/* 문자열 배열과 조합 */
char *Days[] = {"Sunday","Monday","Tuesday",
               "Wednesday","Thursday","Friday","Saturday"};

day d1 = Wed;
printf("%d means %s\n", d1, Days[d1]); // 3 means Wednesday
3 means Wednesday
⚠️
열거형 상수로 정수형만 가능! 문자열이나 실수를 열거형 상수로 사용하면 컴파일 에러가 발생합니다:
enum lastname {"Kim","Lee"}; → ❌
enum realnumbers {pi=3.14}; → ❌

struct Employee e;로 선언된 구조체 변수 e의 salary 필드를 올바르게 참조한 것은?
A e->salary
B (*e).salary
C e.salary
D (*e)->salary
✅ 정답: C — e.salary
e는 구조체 변수이므로 점(.) 연산자를 사용합니다.
A: e->salary는 포인터에 사용. e는 포인터가 아님. ❌
B: (*e).salary는 포인터 e를 역참조. e는 일반 변수. ❌
D: 문법적으로 오류. ❌
QUIZ 03 / 06
struct Employee *pe = &e;로 선언된 포인터 pe를 이용해 salary를 올바르게 참조한 것을 모두 고르시오.
A ①만 가능: pe->salary
B ①과 ④: pe->salary, (*pe).salary
C ①, ②, ④ 모두 가능
D ①, ③, ④ 가능

③ *pe.salary ❌ — *(pe.salary)로 해석됨. pe는 포인터라 pe.salary 자체가 오류
④ (*pe).salary ✅ — 포인터 역참조 후 점 연산자 (①과 동일 의미)
QUIZ 04 / 06
다음 union의 크기는? (int=4B, double=8B)
union mixed { int i; double d; char c; };
A 13 Bytes (4+8+1)
B 8 Bytes (가장 큰 멤버 double)
C 4 Bytes (가장 작은 멤버 기준)
D 1 Byte
✅ 정답: B — 8 Bytes
union의 크기 = 멤버 중 가장 큰 것의 크기.
int(4B), double(8B), char(1B) → 가장 큰 double = 8 Bytes.
struct였다면 최소 4+8+1+패딩 = 16 Bytes가 필요했을 것입니다.
QUIZ 05 / 06
enum colors {white, red=3, blue, green, black=9}; 에서 green의 값은?
A 3
B 4
C 5
D 9
✅ 정답: C — 5
white=0 (기본), red=3 (명시), blue=4 (red+1), green=5 (blue+1), black=9 (명시)
즉: white=0, red=3, blue=4, green=5, black=9
