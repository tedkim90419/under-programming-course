01

변수 (Variable)

💡변수란?

프로그램이 실행되는 동안 값이 변경될 수 있는 데이터 저장 공간입니다. 데이터는 메모리에 저장되며, 각 변수는 이름(식별자)으로 구분됩니다.

  • 변수명은 데이터가 저장된 메모리 주소를 대신함
  • 모든 변수는 특정한 자료형(data type)을 가짐
  • 사용 전에 반드시 선언(declare)되어야 함 → 컴파일 에러 방지
변수 선언 문법 C 
int   value;            // 정수형 변수 선언
float x, y, z;         // 같은 자료형은 한 줄에 선언 가능
int   sum = 0;         // 선언과 동시에 초기화 (권장!)
int   width = 100;
int   area  = width * 200;

⚠️
초기화 주의 적절한 초기값을 대입하지 않으면 실행 결과가 예측 불가능합니다. 변수를 선언할 때 항상 초기값을 지정하는 습관을 기릅시다.
❌ 변수 미사용 
// 크기가 100×200인 사각형의 면적
area = 100 * 200;

// 크기 변경 시 두 곳 수정해야 함
✅ 변수 사용 
int width  = 100;
int height = 200;
area = width * height;

// 코드 재사용성 향상 ✓
02

상수 (Constant)

🔒상수란?

값이 한 번 정해지면 프로그램 실행 중 변하지 않는 데이터입니다.

리터럴 상수 (Literal)

단순하게 값만 표시. 일회성 사용에 적합합니다.

radius = 12;
area   = 3.14 * r * r;
grade  = 'A';

기호 상수 (Symbolic)

여러 번 재사용, 특정 의미 부여가 필요할 때. #define 전처리문 사용.

#define PI      3.141592
#define EX_RATE 1319

area = PI * r * r;
ℹ️
상수도 자료형을 가집니다 코드에서 명시하지 않더라도 100은 int, 3.14는 double, 'A'는 char로 처리됩니다. 컴퓨터 내부에서 올바른 연산을 위해 자료형이 필요합니다.

부동소수점형 (Floating-point Type)

float

  • 32비트 (단정밀도)
  • 유효 숫자 약 6자리
  • 범위: 10⁻³⁸ ~ 10⁺³⁸
float pi = 3.14159f;

double

  • 64비트 (배정밀도)
  • 유효 숫자 약 16자리
  • 범위: 10⁻³⁰⁸ ~ 10⁺³⁰⁸
double pi = 3.141592653;
▸ float (32비트) 내부 구조 — IEEE 754 표준

23 bits
예) ±1.49598 × 10⁸ → 부호(±), 가수(1.49598), 지수(10⁸)
⚠️
실수 연산 오차 주의 컴퓨터는 모든 실수를 정확하게 표현할 수 없습니다. (1.0e20 + 5.0) - 1.0e20의 결과가 0.000000이 됩니다. 연산 순서를 주의 깊게 고려하고, 정밀도가 필요할 때는 double 타입을 사용하세요.

double x;

printf("%f\n", x);  // 기대: 5.0,  실제: 0.000000

// 원인: 1.0e20 + 5.0 연산 시 지수를 큰 쪽으로 맞추면서
//       5.0의 유효숫자가 표현 범위를 벗어나 손실됨

문자형 (Character Type)

🔤char 타입

char는 1바이트(8비트) 크기로, 문자를 숫자(ASCII 코드)로 저장합니다. signed char는 -128~127, unsigned char는 0~255 범위를 표현합니다.

charConst.cLAB
char code = 'A';   // 'A'의 ASCII 값 = 65
char code = 65;    // 위와 동일!

printf("%d %d %d\n", code, code+1, code+2);  // 65 66 67
printf("%c %c %c\n", code, code+1, code+2);  // A  B  C

// 주의: '2' ≠ 2  ('2'의 ASCII 값은 50)
ASCII 코드 인터랙티브 차트 — 클릭하면 값을 확인하세요

sizeof 연산자

📏sizeof(객체)

특정 객체(변수, 상수, 자료형)를 메모리에 저장하기 위해 필요한 바이트 수를 반환합니다. 시스템마다 실제 크기가 다를 수 있어 이식성 높은 코드 작성에 필수적입니다.

sizeof 연산자 사용 예시C
printf("%zu\n", sizeof(char));        // 1 (항상 1)
printf("%zu\n", sizeof(short));       // 2
printf("%zu\n", sizeof(int));         // 4
printf("%zu\n", sizeof(long));        // 4 또는 8
printf("%zu\n", sizeof(float));       // 4
printf("%zu\n", sizeof(double));      // 8
printf("%zu\n", sizeof('+'));         // 4 (char 상수는 int로 처리)
printf("%zu\n", sizeof(3.14159));     // 8 (부동소수점 상수는 double)
printf("%zu\n", sizeof(3.14159f));    // 4 (float)
ℹ️
크기 관계 (C 표준 보장) sizeof(char) = 1  |  sizeof(short) ≤ sizeof(int) ≤ sizeof(long)  |  sizeof(float) ≤ sizeof(double) ≤ sizeof(long double)
07

typedef 키워드

🏷️사용자 정의 자료형

기본 자료형을 토대로 새로운 이름(alias)을 붙여 사용할 수 있습니다. 코드 가독성 향상 및 이식성에 유리합니다.

typedef 사용 예시C
// 기본 문법
typedef 기본자료형  새로운_이름;

// 실제 사용 예
typedef unsigned char  BYTE;    // 임베디드에서 자주 사용
typedef int            INT32;   // 32비트 정수임을 명시
typedef short          INT16;   // 16비트 정수임을 명시

// 이제 새 이름으로 변수 선언 가능
BYTE  index = 0;
INT32 counter = 0;
INT16 sensor_value = 0;
💡
임베디드 시스템에서의 typedef 임베디드 프로그래밍에서는 uint8_t, int16_t, uint32_t 등의 이름을 자주 사용합니다. 이들은 <stdint.h>에 typedef로 정의되어 있습니다.

배운 내용을 확인해 봅시다. 각 문제를 풀고 점수를 확인하세요.

Q1
변수에 대한 설명 중 잘못된 것은?
①변수는 메모리 공간에 할당된다
②변수는 선언할 때 초기화도 같이 할 수 있다
③변수는 프로그램에서 값이 변경되지 않는 요소이다
④변수의 이름도 식별자이다
✅ 정답! ③은 상수(Constant)에 대한 설명입니다. 변수는 프로그램 실행 중 값이 변경될 수 있습니다.
Q2
다음 중 상수의 데이터 타입이 잘못 연결된 것은?
①'\0' → char
②123u → unsigned int
③3.14F → double
④123456L → long
✅ 정답! 3.14F에서 suffix F(또는 f)는 float 타입을 의미합니다. double은 suffix 없이 3.14만 쓸 때 해당합니다.
Q3
32비트 플랫폼에서 데이터 타입과 크기가 올바르게 연결된 것은?
①char — 2 바이트
②short — 4 바이트
③float — 8 바이트
④int — 4 바이트
✅ 정답! char=1바이트, short=2바이트, int=4바이트, float=4바이트입니다.
Q4
다음 코드의 실행 결과는?
short s = 32767; s = s + 1; printf("%d", s);
①32768
②-32768
③0
④컴파일 에러
✅ 정답! 오버플로우(Overflow)가 발생합니다. short의 최대값 32767을 넘으면 최솟값 -32768로 순환됩니다. (2의 보수 표현의 특성)
Q5
'A'의 ASCII 코드 값은 65입니다. 그렇다면 'a' - 'A'의 값은?
①0
②26
③32
④-32
✅ 정답! 'a'=97, 'A'=65이므로 97-65=32. 소문자와 대문자의 ASCII 차이는 항상 32입니다. 이를 이용해 대소문자 변환을 쉽게 할 수 있습니다!
