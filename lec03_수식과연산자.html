수식 (Expression) 과 연산 (Operation)

🧮 수식 (Expression)

연산자(Operator)와 피연산자(Operand)로 구성된, 값(value)을 가지는 구성 단위

  • 연산자: 어떤 연산인지 나타내는 기호 (+ - * / %)
  • 피연산자: 연산의 대상 — 변수, 상수, 또는 또 다른 수식
  • 단일 변수, 단일 상수도 수식으로 간주

⚙️ 연산 (Operation)

주어진 수식을 계산하여 값(value)을 얻어내는 과정

수식 구조
x + y   → 피연산자 + 연산자 + 피연산자
💡 핵심
모든 수식은 결과 값을 가짐 ⟺ 값을 가지는 것은 모두 수식!

이름기호사용 예결과설명

LAB: arithmetic1.c LAB

arithmetic1.c
C
#include <stdio.h>
int main(void) {
    int x, y, result;
    printf("두 개의 정수를 입력하시오: ");
    scanf("%d %d", &x, &y);
    result = x + y;  printf("%d + %d = %d\n", x, y, result);
    result = x - y;  printf("%d - %d = %d\n", x, y, result);
    result = x * y;  printf("%d * %d = %d\n", x, y, result);
    result = x / y;  printf("%d / %d = %d\n", x, y, result); // 정수 몫
    result = x % y;  printf("%d %% %d = %d\n", x, y, result); // %% 로 % 출력
    return 0;
}

💡 % 연산 활용
짝수/홀수 판별: x % 2  |  배수 판별: x % 3 == 0  |  단위 변환 (초 → 분:초 등)
modulo.c
C
#include <stdio.h>
#define SEC_PER_MINUTE  60

int main(void) {
    int input, minute, second;
    printf("초를 입력하시오: ");
    scanf("%d", &input);
    minute = input / SEC_PER_MINUTE;   // 몇 분
    second = input % SEC_PER_MINUTE;   // 몇 초
    printf("%d초는 %d분 %d초입니다.\n", input, minute, second);
    return 0;
}
03

증감 연산자 (Increment / Decrement)

🔢 증감 연산자란?

변수의 값을 1만큼만 증가 또는 감소시키는 단항(unary) 연산자. 주로 반복문에서 카운터 제어에 사용.

  • 전위(Prefix)와 후위(Postfix) 두 가지 형태 존재
  • 단독 사용 시: ++x; ≡ x++; ≡ x = x + 1;
  • 다른 연산자와 함께 쓰일 때 동작이 달라짐!
형태기호실행 방식예시 (x=10일 때)
전위 Prefix ++x 먼저 1 증가 → 나머지 식 진행 y=++x; // x=11, y=11
전위 Prefix --x 먼저 1 감소 → 나머지 식 진행 y=--x; // x=9, y=9
후위 Postfix x++ 먼저 대입 → 나중에 1 증가 y=x++; // y=10, x=11
후위 Postfix x-- 먼저 대입 → 나중에 1 감소 y=x--; // y=10, x=9
전위 증감 — y = ++x (x=10)

① x를 11로 증가  ② y ← 11 대입

→ 증가된 x 값이 y에 대입된다

후위 증감 — y = x++ (x=10)

① y ← 10 대입  ② x를 11로 증가

→ 기존 x 값이 먼저 y에 대입된다

⚠️ 증감 연산자 주의사항
변수에만 사용 가능!   10++ ❌   (x+1)++ ❌

후위 증감은 다른 연산자와 함께 쓰일 때 가장 마지막에 계산됨:
y = (1 + x++) + 10;  // 괄호가 있어도 x 증가는 맨 나중

같은 수식에서 같은 변수를 두 번 이상 쓸 때 증감 연산자 사용 피할 것 — 컴파일러별 결과 다를 수 있음.

대입 연산자 (Assignment Operator)

📝 기본 형식

문법
variable = expression

좌변 (l-value)은 반드시 변수여야 함!

올바른 예 ✓
a = (b=2) + (c=3);
y = x = 3;  // 우결합
잘못된 예 ❌
100 = x + y;
++x = 10;

⚡ 복합 대입 연산자

복합 대입동일 표현
y += expry = y + (expr)
y -= expry = y - (expr)
y *= expry = y * (expr)
y /= expry = y / (expr)
y %= expry = y % (expr)

기타: >>=  <<=  &=  ^=  |=

복합 대입 연산자 예제
C
int x = 10, y = 10, z = 33;
x += 1;          // x = x + 1   → x = 11
y *= 2;          // y = y * 2   → y = 20
z %= 10 + 20;  // z = z % 30  → z = 3
💡 y *= x + 3 의 해석
y *= x + 3  →  y = y * (x + 3)   (y = y*x + 3 이 아님!)

우선순위와 결합규칙 (Precedence & Associativity)

📊 Precedence & Associativity → 연산 순서(evaluation order) 결정

  • Precedence (우선순위): 우선순위가 높은 연산자부터 먼저 적용
  • Associativity (결합규칙): 우선순위가 같은 연산자가 나열되어 있으면 결합규칙에 따라 순서 결정
높음↑ ( ) left to right 괄호
+(unary)  -(unary)  ++  --  sizeof  (type) right to left 단항 연산자
*  /  % left to right 곱셈류
+  - left to right 덧셈류
낮음↓ =  +=  -=  *=  /=  %= right to left 대입 연산자
📝 우선순위 예시
1+2*3      ↔  1+(2*3)
-a*b-c     ↔  ((-a)*b)-c
-++--x     ↔  -(++(--x))  (right-to-left)

형 변환 (Type Conversion)

🤖 ① 묵시적(자동) 변환

컴파일러가 변환 수행

  • 정수적 승격 (Integral Promotion)
  • 산술/대입 연산에 의한 변환 (Arithmetic Conversion)

✍️ ② 명시적 변환 (Type Casting)

프로그래머가 소스코드에 명시

  • 용법: (type) expr
  • 예: (double) num1 / num2

묵시적 변환 ① — Integral Promotion 정수적 승격

📈 Integral Promotion

int 타입보다 작은 범위를 가진 정수형 타입 데이터는 수식 연산 시 자동으로 int 타입으로 변환됨

char → short → int (자동 승격)
💡 Tip
가능하다면 수식에 쓰이는 피연산자의 타입은 일치시키는 게 제일 좋음.

묵시적 변환 ② — 산술/대입 연산 자동 변환 Arithmetic Conversion

🔀 자동 타입 변환 규칙

두 피연산자 타입이 다를 때 데이터 손실을 최소화하는 방향으로 자동 변환

int→ unsigned int→ long→ unsigned long→ float→ double→ long double
Promotion (확장)
double f;
f = 10; // f에는 10.0 저장
Demotion (축소 → 데이터 손실!)
int i;
i = 3.14; // i에는 3만 저장

명시적 변환 — Type Casting Explicit

divTest.c — 정수 vs 실수 나눗셈
C
int num1 = 3, num2 = 4;
double divResult;

divResult = num1 / num2;            // 정수 나눗셈 → 0.000000
printf("나눗셈 결과: %f \n", divResult);

divResult = (double) num1 / num2;  // 실수 나눗셈 → 0.750000
printf("나눗셈 결과: %f \n", divResult);

(double) x = 77  → ((double)x) = 77  컴파일 에러!  캐스팅 결과는 r-value이므로 좌변이 될 수 없음.

단축 계산 (Short-Circuit Evaluation) ⚡ 중요!

⚡ Short-Circuit Evaluation

결과가 첫 번째 수식에서 판가름 나면, 논리 연산자로 연결된 다음 수식을 실행하지 않음!

&& 단축 계산
( 2 > 3 ) && ( ++x < 5 )

첫 항이 거짓(0) → ++x 실행 안 됨!

|| 단축 계산
( 3 > 2 ) || ( --x < 5 )

첫 항이 참(1) → --x 실행 안 됨!

Short-Circuit 활용 예 C 
unsigned int i;
scanf("%d", &i);     // -1 을 입력하면 unsigned이므로 매우 큰 수
if (i < 0 && 1) {    // unsigned는 항상 ≥ 0 이므로 i<0 이 거짓
    printf("negative value\n");
} else {
    printf("0 or positive value\n");
}
💡 !! 연산에 주의
!!5 = !(!(5)) = !(0) = 1
!!s ≠ s  (s=5이면 !!s=1, s=5는 다름)

논리 연산자 활용 예시

char c='B'; int i=3,j=3,k=3; double x=0.0,y=2.3;
ExpressionEquivalent expressionValue
i && j && k(i && j) && k1
x || i && j-3x || (i && (j-3))0
i < j && x < y(i<j) && (x<y)0
'A'<=c && c<='Z'('A'<=c) && (c<='Z')1
c-1=='A' || c+1=='Z'((c-1)=='A') || ((c+1)=='Z')1
ℹ️ 우선순위
&&의 우선순위가 ||보다 높음. 그러나 둘 모두 단항·산술·관계 연산자보다 낮음.

조건 연산자 (Conditional Operator ? :) 삼항 Ternary

❓ 조건 연산자 — C언어의 유일한 삼항 연산자

조건식 expr1
?
값1 expr2
:
값2 expr3
  • expr1을 먼저 실행하여 true/false 판정
  • expr1이 참(true) → expr2 실행, 결과가 전체 수식의 값
  • expr1이 거짓(false) → expr3 실행, 결과가 전체 수식의 값
조건 연산자 활용 예시
C
absolute_value = (x > 0) ? x : -x;    // 절대값
max_value      = (x > y) ? x : y;      // 최대값
min_value      = (x < y) ? x : y;      // 최소값
(age >= 19) ? printf("성인\n") : printf("청소년\n");
char a='a',b='b'; int i=1,j=2; double x=7.07;
ExpressionEquivalentValueType
i==j ? a-1 : b+1 (i==j) ? (a-1) : (b+1) 99 ('c')int

📌 콤마 연산자

  • 콤마(,)로 연결된 수식들: 왼쪽부터 오른쪽으로 순차 실행
  • C 언어 연산자 중 가장 낮은 우선순위
  • for 반복문, 여러 변수 초기화에 주로 사용

    sum += i;

x = (2+3, 5-3);  // x에는 2 저장 (바람직하지 않은 사용)

비트 연산자 (Bitwise Operator)

📚 선수 지식
2진수 표기·비트 논리연산·비트 이동 연산은 중등 수학(2진법), 1학년 2학기 디지털논리설계및실습, 2학년 1학기 전산수학 교과목에서 다루고 있으므로 충분히 복습해 오기 바람.

숫자형 데이터의 비트 표현 2's Complement

🔢 부호 없는 정수 (unsigned)

단순히 10진수를 2진수로 나타낸 것

41 → 이진수 변환
41 = 0···0101001(2)

➖ 부호 있는 정수 (signed) — 2의 보수

음수 -N은 N의 "2의 보수"를 취한 것

  • 1의 보수(bitwise complement)에 1을 더함
  • 0의 2의 보수 = 0 (all bits off)
N이진수 표현 (16-bit)1의 보수2의 보수 (-N)값

8 0000 0000 0000 1000 1111 1111 1111 0111 1111 1111 1111 1000 -8
-7 1111 1111 1111 1001 0000 0000 0000 0110 0000 0000 0000 0111 7

비트 논리 연산 예시

int a = 33333, b = -77777; C 
/* a = 00000000 00000000 10000010 00110101  (33333) */
/* b = 11111111 11111110 11010000 00101111 (-77777) */

a & b  // 00000000 00000000 10000000 00100101 = 32805
a ^ b  // 11111111 11111110 01010010 00011010 = -110054
a | b  // 11111111 11111110 11010010 00111111 = -77249
~(a|b) // 00000000 00000001 00101101 11000000 = 77248
~a&~b  // 00000000 00000001 00101101 11000000 = 77248 (De Morgan!)
💡 De Morgan's Law
~(a | b) == (~a & ~b)  결과가 같음!

비트 이동 연산자 (Shift Operator) << >>

⬅️ 왼쪽 이동 (Left Shift: <<)

expr1 << expr2 — expr2 횟수만큼 왼쪽으로 이동

이동 1회마다 최하위 비트(LSB)에 '0' 채워짐

char c='Z' (=90₁₀) → int로 승격
c 01011010 =90
c<<1 10110100 =180
c<<4 10100000 =1440
💡 수식
n << k = n × 2k (unsigned 기준)

➡️ 오른쪽 이동 (Right Shift: >>)

expr1 >> expr2 — expr2 횟수만큼 오른쪽으로 이동

최상위 비트(MSB) 채움 방식은 타입에 따라 다름

  • unsigned 타입: MSB에 '0' 채움
  • signed 타입: 원래 부호값 또는 '0' (구현 의존)
int a=1<<31 (최상위 비트만 1)

a >> 3 → 1110000...0000 (부호 확장)

unsigned b=1<<31

b >> 3 → 00010000...0000 (0 채움)

💡 수식
n >> k = n ÷ 2k (unsigned 기준)

Q1다음 논리 연산자 중 우선순위가 가장 높은 것은?
✅ ③ ! (논리 NOT)이 단항 연산자로 가장 높음.
우선순위: ! > && > ||
또한 논리 연산자들은 모두 산술·관계 연산자보다 낮은 우선순위를 가짐.
Q2Short-Circuit Evaluation에 대한 설명으로 옳은 것은?
✅ ② A && B 에서 A가 거짓(0)이면 전체는 이미 거짓이므로 B 실행 안 함.
|| 에서는 A가 참(1)이면 전체가 이미 참이므로 B 실행 안 함.
Q3다음 조건 연산자 수식의 결과값과 타입은?
int i=3, j=4; double x=2.5;   i < j ? i + 1 : x
✅ 4.0 (double 타입)
i < j 는 참이므로 i+1 = 4가 선택됨.
그런데 조건 연산자의 두 값의 타입이 다를 때 더 큰 타입으로 자동 변환 → int 4가 double 4.0으로 변환됨.
Q4비트 연산에 관한 다음 설명 중 옳은 것은?
✅ ③ 맞음. n << k == n * 2^k (unsigned 기준)
① 비트 연산자는 정수 타입에만 적용 가능
② ~(a|b) == (~a)&(~b) — De Morgan's Law로 항상 같음
④ signed 타입의 >>는 구현에 따라 MSB에 부호 비트를 채울 수도 있음
Q5다음 코드의 출력 결과는?
int x = 5, y = 3;
printf("%d\n", x > 3 && y < 5);
printf("%d\n", x == 5 || y == 5);
printf("%d\n", !(x > y));
✅ 출력: 1  1  0
① x>3은 참, y<5는 참 → 1 && 1 = 1
② x==5는 참 → 1 || ... = 1 (short-circuit)
③ x>y는 참(1) → !(1) = 0
Q6unsigned char c = 0x55; 일 때 ~c를 int로 출력하면?
(0x55 = 0101 0101(2))
✅ 0xFFFFFFAA
c는 char 타입이므로 ~ 연산 전 int로 승격됨: 0x00000055
~ 적용 → 0xFFFFFFAA
printf("%#x\n", ~c); 출력: 0xffffffaa
