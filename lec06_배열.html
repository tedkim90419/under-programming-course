01

배열의 필요성

💡배열 (Array)이란?

동일한 데이터 타입을 가진 여러 데이터를 하나의 이름(식별자)으로 묶어 저장하는 변수입니다. 배열에 포함된 각 원소는 인덱스(index)로 구분합니다.

😓배열 없이 (비효율)

// 10명의 학생 성적 — 변수 10개!
int grade0, grade1, grade2,
    grade3, grade4, grade5,
    grade6, grade7, grade8,
    grade9;
// 100명이면? 변수 100개... 😱

✅배열 사용 (효율)

// 10명의 학생 성적 — 단 한 줄!
int grade[10];

// 접근도 간편 (루프 활용)
for (i=0; i<10; i++)
  printf("%d\n", grade[i]);
// 1000명도 숫자만 바꾸면 끝! 🎉

02

배열 변수의 선언 (Declaration)

📋선언 문법

배열은 사용하기 전에 반드시 선언(declare)되어야 합니다. 선언은 컴파일러에게 자료형, 이름, 원소 개수를 알려줍니다.

배열 선언 문법 C 
  int     arr    [nItems];
  ↑       ↑        ↑
  데이터  배열변수  원소 개수
  타입    이름      (상수 권장)

✅Good Practice — #define 활용

#define N 100   // 배열 원소 개수 상수화
int arr[N];  /* a[0] ... a[99] 할당 */

for (i = 0; i < N; ++i)
  sum += arr[i];

크기를 변경할 때 한 곳만 수정하면 됩니다!

📌선언 시 결정되는 것

  • 데이터 타입: 기본 자료형 모두 가능 (int, float, char, double…)
  • 배열 이름: 식별자 규칙에 따라 의미 있는 이름 사용
  • 원소 개수: 일반적으로 정수 상수 사용
  • 유효 인덱스: 0 ~ (N-1)
⚠️
VLA (Variable Length Array) 주의 C99 이후 정수형 변수로 배열 크기를 지정하는 VLA가 허용되지만, 모든 C 컴파일러가 VLA를 지원한다는 보장이 없습니다. 호환성을 위해 #define 상수 또는 const 정수 상수 사용을 권장합니다.
선언 원소 수 메모리 유효 인덱스

double d[3];324 Bytes0 ~ 2

03

배열 원소 접근 (Indexing)

🎯인덱스로 원소 접근

배열 인덱스 연산자 []와 인덱스 값을 이용해 각 원소를 읽거나 쓸 수 있습니다.

  • 인덱스는 상수, 변수, 정수 수식 모두 가능
  • 예: grade[5], grade[i], grade[i-1], grade[i++]
  • 유효 범위: 0 ~ (원소개수 - 1)
인터랙티브 배열 인덱스 탐색기 — int grade[10]
셀을 클릭하거나 인덱스를 입력해서 접근해보세요
🚨
범위 초과 인덱스 → Runtime Error! 유효 범위 밖의 인덱스 (< 0 또는 > (nItems-1))를 사용하면 런타임 에러가 발생합니다. C 컴파일러는 이를 자동으로 검사하지 않으므로 프로그래머가 직접 주의해야 합니다.

배열의 초기화 (Initialization)

🔧초기화 방법

중괄호 {} 안에 원소 개수만큼 초기값을 나열하고, 각 값은 ,로 구분합니다.

기본 초기화C
float f[5] = { 0.0, 1.0, 2.0, 3.0, 4.0 };
// f[0]=0.0, f[1]=1.0, f[2]=2.0, f[3]=3.0, f[4]=4.0

int scores[5] = { 10, 20 };
// scores[0]=10, scores[1]=20
// scores[2]=0, scores[3]=0, scores[4]=0  ← 자동으로 0

int a[100] = { 10 };
// a[0]=10, a[1]~a[99] = 전부 0

int b[5] = { }; // 또는 = {0}

💡
원소 개수보다 적은 수의 초기값을 쓰면, 주어진 수만큼만 초기화하고 나머지는 모두 0으로 채워집니다.
크기 생략 — 컴파일러가 자동 결정C
// 원소 개수를 명시하지 않으면
// 초기화 값의 개수가 배열 크기가 됨
int scores[] = { 10, 20, 30, 40, 50 };
// ↑ int scores[5] 와 완전히 동일

// 컴파일러가 초기화 값 개수를 세어서 크기 결정
🔍
크기를 명시하는 편이 코드 가독성과 유지보수에 유리합니다. 하지만 초기화 목록이 길 때 크기 생략이 편리합니다.
문자 배열 초기화 — NULL 문자 주의!C
// 방법 1: 문자열 리터럴로 초기화
char s[] = "abc";   // ← 크기는 4! (not 3)

// 위 선언을 컴파일러는 아래처럼 해석:
char s[] = { 'a', 'b', 'c', '\0' };
//                              ↑ NULL 문자 자동 삽입!
s[0]
s[1]
s[2]
s[3]
'a'
'b'
'c'
'\0'
🚨
문자 배열의 크기는 문자 수 + 1! "abc"는 3개 문자처럼 보이지만 NULL 문자 '\0'이 마지막에 자동 삽입되어 배열 크기는 4가 됩니다.
⚠️
초기화를 하지 않으면? 지역 변수 배열은 쓰레기 값(garbage)이 들어갑니다. 전역/정적 배열은 자동으로 0으로 초기화됩니다. 명시적 초기화를 항상 권장합니다!
05

기본적인 배열 다루기

📋 배열 내용 복사하기

❌이렇게 하면 안 됨!

int a[5] = {1,2,3,4,5};
int b[5];

b = a; // ❌ 컴파일 에러!
// 배열 이름은 주소 상수
// 대입 연산 불가

✅원소 하나씩 복사

int a[5] = {1,2,3,4,5};
int b[5];

for (int i=0; i<5; i++)
  b[i] = a[i]; // ✅ OK

🔍 두 배열의 내용 비교하기

❌이렇게 하면 안 됨!

int a[5] = {1,2,3,4,5};
int b[5] = {1,2,3,4,5};

if (a == b) // ❌ 주소 비교!
  printf("같습니다\n");
// 항상 "다릅니다" 출력됨
// (a, b는 다른 메모리 주소)

✅원소 하나씩 비교

for (int i=0; i<5; i++)
  if (a[i] != b[i]) {
    isDiff = 1; break;
  }

if (!isDiff)
  printf("같습니다\n"); // ✅
💡
배열 이름 = 시작 주소 C에서 배열 이름 a, b는 각 배열의 첫 번째 원소의 주소(포인터 상수)입니다. 따라서 a == b는 값 비교가 아니라 주소 비교가 됩니다.

📐 배열 원소 개수 알아내기 (sizeof 활용)

LAB: p9.c — sizeof로 원소 개수 계산
C 
int a[] = {1, 2, 3, 4, 5, 6};
int nItems;

/* 배열 전체 크기 / 원소 하나 크기 = 원소 개수 */
nItems = sizeof(a) / sizeof(a[0]);
//         24 Bytes /   4 Bytes   =    6

printf("원소 개수 = %d\n", nItems); // 6
sizeof 원소 개수 계산기

다차원 배열 (Multi-dimensional Array)

🧊다차원 배열 = "배열의 배열"

차원이 하나씩 늘어날 때마다 각괄호 [] 쌍을 하나씩 더 사용합니다.

  • 대표적 활용: 행렬 연산, 이미지 데이터 처리
  • 일반적인 응용에서는 2차원 또는 3차원까지만 사용
LAB: p10.c — 다차원 배열 선언
C 
int a[10];        // 1차원: 정수 10개   → 40 Bytes
int b[2][7];     // 2차원: 정수 2×7=14개 → 56 Bytes
int c[5][3][2];  // 3차원: 정수 5×3×2=30개 → 120 Bytes
차원선언 예시원소 수메모리접근 방식
1차원int a[10]1040 Ba[i]
2차원int b[2][7]1456 Bb[i][j]
3차원int c[5][3][2]30120 Bc[i][j][k]

2차원 배열 (Two-dimensional Array)

📊2차원 배열의 구조

행(Row)과 열(Column)을 가지는 직사각형 형태의 원소 집합. 실제 메모리에서는 연속적인 1차원 선형 공간에 저장됩니다.

인터랙티브 2차원 배열 — int a[3][5]

셀을 클릭하면 해당 원소의 인덱스 정보가 표시됩니다.

▶ 셀을 클릭해 원소를 선택하세요

💾 메모리 저장 방식 — 행 우선 (Row-major)

🔗Row-major Convention

C 언어는 2차원 배열을 행 우선(Row-major) 방식으로 메모리에 저장합니다. 가장 오른쪽 인덱스(열)가 먼저 변화합니다.

int a[3][5] — 메모리 선형 배치 (row-major)
a[0][0]0
a[0][1]1
a[0][2]2
a[0][3]3
a[0][4]4
a[1][0]5
a[1][1]6
a[1][2]7
a[1][3]8
a[1][4]9
a[2][0]10
a[2][1]11
a[2][2]12
a[2][3]13
a[2][4]14
← a[0] (row 0, 5개) →
← a[1] (row 1, 5개) →
← a[2] (row 2, 5개) →

🔧 2차원 배열 초기화

행별 중괄호 명시 (권장)C
int a[2][3] = { {1, 2, 3}, {4, 5, 6} };
// 또는 가독성을 위해:
int a[2][3] = {
  {1, 2, 3},  // row 0
  {4, 5, 6}   // row 1
};
내부 중괄호 생략 — Row-major 순서로 채움C
int a[2][3] = {1, 2, 3, 4, 5, 6};
// 결과는 위와 동일하지만 가독성이 낮음
// row 0: {1,2,3}, row 1: {4,5,6}
⚠️
내부 중괄호를 생략해도 동작하지만, 코드 가독성을 위해 행별 중괄호 명시를 권장합니다.
부분 초기화 — 나머지는 0C
int a[2][3] = {1, 2, 3, 4};
// row 0: {1, 2, 3}
// row 1: {4, 0, 0}  ← 나머지 0으로 채워짐
첫 번째 차원(행) 크기 생략C
int a[][3] = { {1,2,3}, {4,5,6} };
// 내부 중괄호 쌍의 개수(2) → int a[2][3]

int b[3][];  // ❌ 허용 안 됨!
// 첫 번째 차원만 생략 가능
// 열(column) 크기는 반드시 명시!
💡
크기 생략 규칙: 첫 번째 차원(행)만 생략 가능. 나머지 차원은 반드시 명시해야 합니다.

3차원 배열 (Three-dimensional Array)

🧊3차원 배열 구조

인덱스 의미: a[plane][row][column]

2차원 배열과 동일한 초기화 원칙이 적용됩니다.

3차원 배열 초기화 예시
C 
int a[2][2][3] = {
  { {1, 1, 0}, {2, 0, 0} },  // plane 0
  { {3, 0, 0}, {4, 4, 0} }   // plane 1
};

// 첫 번째 차원(plane) 생략도 가능:
int b[][2][3] = {
  { {1, 1}, {2} },
  { {3},    {4, 4} }
};

// 모든 원소를 0으로 초기화:
int c[2][2][3] = { 0 };

다음 중 배열의 선언 및 초기화가 잘못된 것을 고르시오.
① int arr[3] = { };
② int arr[3] = { 10 };
③ int arr[] = { 10, 20, 30, 40 };
④ int arr[3] = { 10, 20, 30 };
⑤ int arr[ ];
A ①만 잘못됨
B ③과 ④가 잘못됨
C ⑤만 잘못됨
D ①과 ⑤가 잘못됨
✅ 정답: C — ⑤만 잘못됨
① int arr[3] = { }; — 크기 지정 + 빈 중괄호: 대부분 컴파일러가 0으로 초기화. 유효.
② int arr[3] = { 10 }; — 부분 초기화: arr[0]=10, arr[1]=arr[2]=0. 유효.
③ int arr[] = { 10, 20, 30, 40 }; — 크기 생략 후 초기화: arr[4]로 선언됨. 유효.
④ 정상적인 선언. 유효.
⑤ int arr[ ]; — 크기도 없고 초기화도 없음 → 컴파일 에러!
QUIZ 02 / 05
다음 중 문자 배열의 초기화가 잘못된 것을 모두 고르시오.
① char str[6] = { 'A','B','C','D','E','\0' };
② char str[6] = 'A';
③ char str[6] = "ABCDE";
④ char str[] = "ABCDE";
⑤ char str[6] = 'A','B','C','D','E','\0';
A ②만 잘못됨
B ②와 ⑤가 잘못됨
C ①, ③, ⑤가 잘못됨
D ②, ④, ⑤가 잘못됨
✅ 정답: B — ②와 ⑤
② char str[6] = 'A'; — 문자 하나를 배열에 직접 대입 불가. 컴파일 에러!
⑤ char str[6] = 'A','B',...; — 중괄호 없이 쉼표 나열은 문법 오류. 컴파일 에러!
①은 정상적인 문자 배열 초기화. ③은 문자열 리터럴로 초기화 (유효). ④는 크기 생략 후 초기화 (유효, str[6]).
QUIZ 03 / 05
int a[100] = { 10 }; 으로 선언된 배열에서 a[99]의 초기값은?
A 가비지 값이 들어간다.
B 0
C 99
D 시스템에 따라 달라진다.
✅ 정답: B — 0
부분 초기화 규칙: 원소 개수(100)보다 적은 초기값(1개: 10)을 지정하면, a[0] = 10이 되고 나머지 a[1] ~ a[99]는 모두 0으로 자동 초기화됩니다. 이는 C 표준에서 보장하는 동작입니다.

Row-major 순서로 채워집니다:
a[0][0]=1, a[0][1]=2 (row 0)
a[1][0]=3, a[1][1]=4 (row 1)
따라서 a[1][1] = 4.

아래 코드에서 오류가 발생할 수 있는 부분을 모두 고르시오.
#define MAX_SIZE 3
int main(void)
{
  int a[MAX_SIZE] = { 0, 1, 2, 3 };  // (가)
  int b[3.0];                        // (나)
  int i;
  for (i = 0; i <= MAX_SIZE; i++)   // (다)
    b[i] = a[i];
  return 0;
}
A (가)만 오류
B (나)만 오류
C (가)와 (나) 오류
D (가), (나), (다) 모두 오류
✅ 정답: D — 세 곳 모두 오류
(가) int a[3] = {0,1,2,3}; — 크기(3)보다 초기값이 많음(4개) → 컴파일 경고/오류
(나) int b[3.0]; — 배열 크기는 정수여야 함. 실수(3.0) 사용 불가 → 컴파일 에러
(다) i <= MAX_SIZE → i가 0,1,2,3 범위. MAX_SIZE=3이므로 a[3], b[3] 접근 → 유효 인덱스(0~2) 초과 → 런타임 오류!
