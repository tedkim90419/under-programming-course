변수와 메모리 주소

🧠변수는 메모리 위치다

변수는 메모리 상의 특정 주소(address)로부터 일정한 크기를 차지하며 값이 저장됩니다.

  • 주소는 바이트(byte) 단위로 1씩 증가
  • 여러 바이트를 차지하는 변수의 주소 = 시작 주소
  • 컴파일러가 자료형에 따라 메모리 공간에 일정 길이의 바이트 할당

📍포인터(Pointer)란?

메모리 상의 주소를 저장하는 변수입니다. 변수 값 자체가 아닌 다른 변수의 주소를 저장하여, 간접적으로 변수 값에 접근합니다.

  • 대표적 활용: 함수 호출 시 데이터 복사 없이 주소 전달 (Call-by-Reference)
  • 동적으로 변하는 자료구조 표현 (linked list, tree …)
  • 동적 메모리 할당 관리
02

포인터 변수의 선언

포인터 변수 선언 문법C
int  * p;      // int를 가리키는 포인터
↑       ↑  ↑
데이터  *  변수명
타입   (포인터 표시)

float  *pf;   // float를 가리키는 포인터
char   *pc;   // char를 가리키는 포인터
double *pd;   // double을 가리키는 포인터

❓왜 타입이 필요한가?

포인터가 가리키는 주소에서 몇 바이트를 읽을지 알아야 합니다. int*는 4바이트, double*는 8바이트를 읽습니다. 타입 없이는 값을 올바르게 해석할 수 없습니다.

⚠️여러 개 선언 시 주의!

// p1, p2, p3 모두 포인터
int *p1, *p2, *p3;

// ⚠️ p1만 포인터! p2, p3는 int!
int *p1, p2, p3;
📏
포인터 변수의 크기 포인터 변수 자체의 크기는 가리키는 데이터 타입과 무관하게 32비트 시스템: 4 Bytes / 64비트 시스템: 8 Bytes입니다. sizeof(int*) == sizeof(double*)
03

& (Address-of) / * (Dereference) 연산자

📌& — 주소 연산자 (Address-of)

변수의 메모리 시작 주소를 반환합니다.

  • 피연산자는 변수만 가능 (상수·수식 불가)
  • &i → i가 저장된 주소 (예: 100)
  • 오른쪽에서 왼쪽 결합
int  i  = 10;
int *pi = &i;   // pi = 100 (i의 주소)
// p = &3;      ← ❌ 컴파일 에러
// p = &(i+2);  ← ❌ 컴파일 에러

🔍* — 간접 참조 연산자 (Dereference)

포인터가 가리키는 주소의 데이터 값에 접근합니다.

  • 피연산자는 포인터 타입 변수만 가능
  • *pi → pi가 가리키는 주소의 값 (10)
  • 읽기(r-value)와 쓰기(l-value) 모두 가능
int *pi = &i;
printf("%d", *pi); // 읽기: 10
*pi = 99;          // 쓰기: i = 99

📊포인터 연산 표현식 예시

포인터 초기화 & 주의사항

🚨
초기화되지 않은 포인터는 극도로 위험! 포인터 변수를 초기화 없이 역참조(*p)하면 임의의 메모리 주소를 건드려 프로그램 크래시, 데이터 손상이 발생합니다.
LAB: p9.c, p13.c — 포인터 초기화
C
int *p;       // ❌ 초기화 안 됨 — p는 쓰레기 주소
*p = 100;   // 🚨 아주 위험한 코드! 임의 메모리에 씀

// ✅ 올바른 초기화 방법들
int i;
int *p1 = &i;     // 가장 일반적인 방법
int *p2 = NULL;  // NULL로 초기화 (사용 전 체크)

// NULL 포인터 체크 패턴
if (p2 == NULL)
  printf("NULL pointer error\n");

// ❌ 타입 불일치 — 위험!
int    i;
double *pd = &i;  // double*로 int를 가리킴
*pd = 36.5;       // 실제 메모리 8바이트를 쓰지만 i는 4바이트!

✅NULL 포인터 패턴

포인터를 바로 초기화할 대상이 없을 때는 NULL(0)로 초기화하고, 사용 전에 반드시 NULL 여부를 체크합니다.

❌타입 불일치 위험

포인터 변수의 자료형과 가리키는 변수의 자료형은 반드시 일치시켜야 합니다. 불일치 시 잘못된 메모리 범위를 접근합니다.

포인터 산술 연산 & 증감 연산자

➕포인터에 허용되는 연산

포인터 변수에는 증가(++), 감소(--), 덧셈(+), 뺄셈(-)만 허용됩니다.

  • 증가/감소 단위는 가리키는 타입의 크기(sizeof)만큼 변함
  • pc++ → +1 byte / pi++ → +4 bytes / pd++ → +8 bytes

각 포인터를 1 증가(++)했을 때의 주소 변화
초기(10000)
++ 후
▶ 실행을 눌러보세요

⚡ 간접 참조 연산자 + 증감 연산자 우선순위

📋
우선순위: 전위 ++/-- == &(주소) == *(역참조) (모두 같은 우선순위, 오른→왼 결합) 따라서 *p++는 *(p++)이고 *++p는 *(++p)입니다.
수식동일 표현설명
v = *p++ v=*p; p++; p가 가리키는 값을 v에 대입 후, p(주소)를 증가
v = (*p)++ v=*p; *p=*p+1; p가 가리키는 값을 v에 대입 후, *p(값)을 증가 (주소 변동 없음)
v = *++p ++p; v=*p; p(주소)를 먼저 증가 후, 새 주소의 값을 v에 대입
v = ++*p *p=*p+1; v=*p; *p(값)를 먼저 증가 후 v에 대입 (주소 변동 없음)
⚠️
증가/감소의 대상이 주소(pointer 자체)인지, 주소에 저장된 값(*p)인지 항상 구분하세요!

포인터와 배열의 관계

🔗배열 이름 = 배열의 시작 주소!

수식이나 함수 인자로 사용된 배열 이름은 포인터와 동등하게 처리됩니다.

  • 인덱스는 시작 주소로부터의 오프셋(offset)으로 취급됨
  • 차이점: 포인터 변수는 값 변경 가능 / 배열 이름은 상수 (변경 불가)
배열-포인터 동등 표현
C
int *p, *q;
int  a[4];

p = a;       /* p = &a[0]; 와 동일 */
q = a + 2;   /* q = &a[2]; 와 동일 */
p = a + i;   // ✅ OK — 포인터는 변수
a = q;       // ❌ Error — 배열 이름은 상수

// 다음 네 가지는 모두 동일!
a[i]   // 배열 인덱스
*(a+i) // 포인터 + 오프셋
*(p+i) // 포인터 변수
p[i]   // 포인터에 [] 연산자

// sizeof 차이 (a가 int[4]일 때)
sizeof(a)  // 16 (배열 전체 크기)
sizeof(p)  // 4 또는 8 (포인터 하나 크기)

📊배열 합 구하기 — 3가지 포인터 버전

LAB: p16.c
C
#define N 10
int *p, a[N], sum = 0;

/* Version 1: 포인터 + 오프셋 */
for (i = 0; i < N; ++i)
  sum += *(a+i); // 또는 a[i]

/* Version 2: 포인터 이동 (주소 비교) */
for (p = a; p <= &a[N-1]; ++p)
  sum += *p;

/* Version 3: 포인터를 배열처럼 */
for (p = a, i = 0; i < N; ++i)
  sum += p[i]; // 또는 *(p+i)
07

포인터와 함수 (Call-by-Reference)

📞Call-by-Reference 구현 방법

  1. 함수 매개변수를 포인터 타입으로 선언
  2. 호출 시 & 연산자로 변수 주소를 인자로 전달
  3. 함수 내부에서 * 연산자로 역참조해서 원본 값 변경

Call-by-Value vs Call-by-Reference — swap 함수 비교

❌Call-by-Value (원본 불변)

void swap(int p, int q) {
  int tmp = p;
  p = q; q = tmp;
  // p, q는 복사본
}
int i=3, j=5;
swap(i, j);
printf("%d %d", i, j);
3 5 ← 원본 그대로!

✅Call-by-Reference (원본 변경)

void swap(int *p, int *q) {
  int tmp = *p;
  *p = *q; *q = tmp;
  // *p, *q로 원본 직접 변경
}
int i=3, j=5;
swap(&i, &j);   // 주소 전달
printf("%d %d", i, j);
5 3 ← 교환 성공!

배열 매개변수 = 포인터

🔗배열로 선언된 매개변수의 실체

함수에 배열이 전달되면 실제로는 배열의 시작 주소(포인터)가 전달됩니다 (Call-by-Reference 효과). 배열 원소 자체는 복사되지 않습니다.

LAB: p20.cC
// 두 선언은 완전히 동일!
double sum(double a[], int n)  // 배열 표기
double sum(double *a, int n) // 포인터 표기
// 함수 내에서 배열 길이를 알 수 없음 → 별도 파라미터로!

Return by Parameter (다중 반환값)

📤결과가 2개 이상일 때

함수의 return은 값 하나만 반환 가능합니다. 여러 결과를 반환하려면 결과를 저장할 변수의 주소를 매개변수로 전달합니다. scanf()가 대표적인 예입니다.

LAB: p22.c — 합과 차를 동시에 반환C
// scanf: return = 읽은 개수, 실제 값은 포인터로 저장
int i, j, count;
count = scanf("%d %d", &i, &j);

// 합과 차를 동시에 반환하는 함수 설계
void sum_and_diff(int a, int b,
                   int *sum, int *diff) {
  *sum  = a + b;  // 결과를 포인터로 저장
  *diff = a - b;
}
int s, d;
sum_and_diff(10, 3, &s, &d);
// s=13, d=7
🚨
지역 변수 주소를 반환하면 안 된다! 함수가 반환한 후 지역 변수의 스택 공간은 즉시 해제됩니다. 지역 변수의 주소를 return하면 dangling pointer가 되어 가비지 값 또는 런타임 에러가 발생합니다.
int *add(int x,int y){int result=x+y; return &result;} // ❌ 위험!
08

포인터 활용 [고급편]

🌐void 포인터 (Generic Pointer)

특정 타입과 무관하게 어떤 주소든 저장할 수 있는 제네릭 포인터입니다.

  • 장점: 다양한 타입의 인자를 받는 함수 구현에 유용 (예: malloc())
  • 단점: 포인터 산술 연산 불가, 역참조 불가 (타입 캐스팅 필수)
LAB: p24.c — void 포인터
C
int   a = 10;
void *p;
p = &a;               // OK: 어떤 주소든 저장 가능
printf("%d\n", *p);        // ❌ 컴파일 에러 — 타입 모름
printf("%d\n", *(int*)p); // ✅ 타입 캐스팅 후 역참조
p++;                       // ⚠️ 산술 연산 불가 (컴파일러 경고)

🔗이중 포인터 (Double Pointer)

또 다른 포인터 변수의 주소를 가리키는 포인터입니다. int **ppi.

LAB: p25.c — 이중 포인터
C
int   i   = 10;       // 주소: 1000
int  *pi  = &i;       // pi = 1000, 주소: 1010
int **ppi = &pi;      // ppi = 1010, 주소: 1020

*pi   = 20; // i = 20
**ppi  = 30; // *(*ppi) = *(pi) = i → i = 30
printf("i=%d\n", i); // 30
// ppi → pi → i 순서로 역참조

📦포인터 배열 (Array of Pointers)

각 원소가 그 자체로 개별적인 포인터 변수인 배열입니다.

LAB: arrayOfPtrs.c
C
int  a=10, b=20, c=30, d=40;
int *ap[4] = { &a, &b, &c, &d };
// ap[0]=&a, ap[1]=&b, ap[2]=&c, ap[3]=&d

printf("%d\n", *ap[0]); // 10
printf("%d\n", *ap[2]); // 30

🧩비정형 배열 (Ragged Arrays)

다양한 크기의 배열을 가리키는 포인터들로 구성된 배열입니다. 각 행의 길이가 달라도 됩니다.

LAB: raggedArray.c
C
// 문자열 포인터 배열 (다른 길이의 문자열)
char *p[2] = { "abc", "a is for apple" };
// p[0] → "abc" (4바이트)
// p[1] → "a is for apple" (15바이트)

// 숫자형 비정형 배열 (-1로 행 끝 표시)
int row_1[] = { 1,2,3,4,5,-1 };
int row_2[] = { 6,7,-1 };
int row_3[] = { 8,9,-1 };
int *weights[] = { row_1, row_2, row_3 };
char a[2][15] (2D 배열)
메모리: 30 bytes 고정
내용 변경 가능
char *p[2] (포인터 배열)
포인터 16B + 데이터 19B
문자열 상수 → 내용 변경 불가

⌨️main() 함수의 인자

커맨드라인 인자를 받기 위해 main()에 두 매개변수를 선언합니다.

  • argc: 커맨드라인 인자의 개수
  • argv: 각 인자를 가리키는 문자열 포인터 배열 (char *argv[] == char **argv)
LAB: myEcho.c — 커맨드라인 인자
C
void main(int argc, char *argv[])
{
  int i;
  printf("argc = %d\n", argc);
  for (i = 0; i < argc; ++i)
    printf("argv[%d] = %s\n", i, argv[i]);
}
// 실행: ./myEcho a is for apple
// argc=5, argv[0]="./myEcho", argv[1]="a", ...

📊2차원 배열과 포인터

int a[3][5]에서 a[i]는 i번째 행을 가리키는 포인터와 동일합니다 (a[i] == *(a+i)).

LAB: p31.c — 2D 배열 포인터 표현
C
int a[3][5];

/* a[i][j]의 다양한 표현 (모두 동일!) */
a[i][j]                // 일반 표기
*(a[i] + j)           // a[i]는 행 포인터
(*(a+i))[j]           // *(a+i) = a[i]
*((*(a+i)) + j)        // 완전 포인터 표현

// 주소 관계: a, a[0], &a[0][0] 모두 같은 주소!
printf("%p %p %p\n", a, a[0], &a[0][0]);

// sizeof 차이
sizeof(a)    // 60 = 3×5×4
sizeof(a[0]) // 20 = 5×4 (한 행)

const 키워드와 포인터

🔒const 키워드

변수를 읽기 전용으로 만듭니다. 포인터와 함께 쓸 때 위치에 따라 의미가 완전히 다릅니다!

🔒const char *p

p가 가리키는 값을 변경할 수 없음. p 자체(주소)는 변경 가능.

const int *p = &a;
*p = 3;   // ❌ 에러: 값 변경 불가
p  = &b;  // ✅ OK: 주소 변경 가능

📌char * const p

p 자체(주소)를 변경할 수 없음. p가 가리키는 값은 변경 가능.

int * const p = &a;
*p = 3;   // ✅ OK: 값 변경 가능
p  = &b;  // ❌ 에러: 주소 변경 불가
선언*p (값) 변경p (주소) 변경특징
int *p✅ 가능✅ 가능일반 포인터
const int *p❌ 불가✅ 가능가리키는 값 보호
int * const p✅ 가능❌ 불가포인터 자체 보호
const int * const p❌ 불가❌ 불가둘 다 보호 (완전 읽기전용)
💡
읽는 법: const는 바로 오른쪽에 있는 것을 수식 const int *p → const가 int 앞 → "const int를 가리키는 포인터" → 값 변경 불가
int * const p → const가 p 앞 → "const 포인터" → 주소 변경 불가

동적 메모리 할당 (Dynamic Memory Allocation)

🧱정적 메모리 할당 (Static)

  • 프로그램 시작 시 크기 고정
  • 예: int arr[10];
  • 실행 중 크기 변경 불가
  • 더 큰 입력 → 처리 불가
  • 더 작은 입력 → 공간 낭비

🌊동적 메모리 할당 (Dynamic)

  • 실행 중 필요한 시점에 필요한 만큼 할당
  • Heap 영역에 할당
  • 사용 후 반드시 시스템에 반납
  • malloc(), free() 등 활용
  • 관리는 프로그래머 책임!

malloc / calloc / realloc / free

함수프로토타입설명사용 예
malloc void *malloc(size_t size) size 바이트 할당, 초기화 없음, 실패 시 NULL 반환 p=(char*)malloc(100)
calloc void *calloc(size_t n, size_t size) n×size 바이트 할당, 전부 0으로 초기화 p=(int*)calloc(5,sizeof(int))
realloc void *realloc(void *ptr, size_t size) 기존 동적 할당 영역 크기 변경, 기존 데이터 보존 p=(int*)realloc(p, 7*sizeof(int))
free void free(void *ptr) 동적 할당된 메모리 반환 free(p)
📌
헤더: #include <stdlib.h>
dynamic_mem.c — malloc + realloc 예시
C
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
  int  *pi;
  pi = (int*)malloc(5 * sizeof(int));

  /* ① 반드시 NULL 체크! */
  if (pi == NULL) {
    printf("메모리 할당 오류\n");
    exit(1);
  }

  pi[0]=1; pi[1]=2; pi[2]=3; pi[3]=4; pi[4]=5;

  /* ② 사용 후 반드시 free */
  free(pi);
  pi = NULL; // dangling pointer 방지
  return 0;
}

/* realloc 예시: 2개 → 3개로 확장 */
int *list = (int*)malloc(sizeof(int) * 2);
list[0] = 10; list[1] = 20;

int *list_new = (int*)realloc(list, sizeof(int) * 3);
list_new[2] = 30;  // 기존 데이터(10, 20) 보존!

🚨① 항상 NULL 체크

malloc/calloc/realloc은 실패 시 NULL 반환. 반드시 확인 후 사용!

💧② 메모리 누수 방지

할당한 메모리는 반드시 free() 호출. 함수에서 포인터 잃으면 해제 불가 → Memory Leak!

👻③ Dangling Pointer

free() 후 해제된 메모리를 다시 참조하면 런타임 에러. free() 후 포인터를 NULL로!

코드 뽀개기 — 3가지 위험 패턴C
/* ❌ 패턴 1: dangling pointer */
int *pi = (int*)malloc(5*sizeof(int));
free(pi);
*pi = 10;  // 🚨 해제된 메모리 접근!

/* ❌ 패턴 2: memory leak (sub 호출마다 200*4 = 800B 누수) */
void sub(void) {
  int *p1 = (int*)malloc(100*sizeof(int));
  int *p2 = (int*)malloc(100*sizeof(int));
  return; // free() 없이 반환 → 누수!
}

/* ❌ 패턴 3: NULL 미체크 */
char *pc = (char*)malloc(1);
*pc = 'a'; // malloc 실패 시 (pc==NULL) → 🚨 크래시!

/* ✅ 올바른 패턴 */
int *p = (int*)malloc(5*sizeof(int));
if (p == NULL) { exit(1); }
/* 사용... */
free(p); p = NULL; // dangling ptr 방지

QUIZ 02 / 06
short num=10; (주소 0x1230) / short *p=&num; (주소 0x1240) 일 때,
printf("%d", *p)의 출력은?
A 0x1230
B 10
C 0x1240
D 4 또는 8
✅ 정답: B — 10
*p는 p가 가리키는 주소(0x1230)에 있는 값을 역참조합니다. 그 값은 num = 10입니다.
p(주소 출력) = 0x1230 / &p(포인터 변수의 주소) = 0x1240 / sizeof(p) = 2 또는 4 또는 8 (short* 크기) / p+1 = 0x1232 (short는 2바이트)
QUIZ 03 / 06
int a=5; int *p=&a; 일 때, v = *p++ 실행 후 v와 a의 값은?
A v=6, a=6 (a가 증가)
B v=5, a=5 (p 주소만 증가, a 불변)
C v=5, a=6 (a가 증가)
D v=6, a=5
✅ 정답: B — v=5, a=5
*p++ = *(p++): 후위 증가이므로 먼저 *p(=5)를 v에 대입한 후, p의 주소를 1 증가시킵니다.
a의 값은 변하지 않고, p만 다음 int 주소를 가리키게 됩니다.
만약 v = (*p)++이었다면: v=5, a=6 (a의 값이 증가).
QUIZ 04 / 06
int x[10]; int *p=x; 일 때, 의미가 다른 것은?
① *(x+i)   ② x[i]   ③ p+i   ④ p[i]
A ③ p+i
B ① *(x+i)
C ② x[i]
D 모두 동일
✅ 정답: A — ③ p+i
①*(x+i), ②x[i], ④p[i]는 모두 i번째 원소의 값을 나타냅니다.
③p+i는 i번째 원소의 주소를 나타냅니다. 값이 아닙니다!
값을 원한다면 *(p+i)로 역참조해야 합니다.

B ②
