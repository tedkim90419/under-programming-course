if 조건문 (if Statement)

📐 if statement 구조

문법 (Syntax)
if (조건식) { statement 1; ... } external_statement;
  • 조건식이 참(Non-zero)이면 블록 내 문장 실행
  • 조건식이 거짓(Zero)이면 블록 건너뜀
  • 조건식에는 일반적으로 관계/논리 연산자 사용
  • external_statement는 항상 실행
↓
조건식 (Expression)
True (Non-zero)
↓
statement 1
...
↓
False (Zero)
↓
↓
external_statement

예시 코드

if 조건문 예시
C
// 예시 1: y가 0이 아닐 때만 나눗셈
if (y != 0.0)
    x /= y;

// 예시 2: 온도가 0 미만일 때만 출력
if (temperature < 0)
    printf("현재 영하입니다.\n");    // 조건이 참일 때만 실행

printf("현재 온도는 %d 도 입니다.\n", temperature); // 항상 실행

복합문 (Compound Statement) — 블록 중요!

📦 복합문 (Block)

조건식이 참일 때 수행할 문장이 여러 개이면 중괄호 { }로 묶은 복합문(블록) 활용

  • 블록(block)이라고도 함 — 중괄호로 묶인 선언문과 실행문 그룹
  • 블록에 포함된 문장들은 모두 적절한 들여쓰기(indentation) 필수!
  • Python과 다른 점: C언어는 들여쓰기만으로는 블록 범위 구분 안 됨 → 중괄호 필수!
❌ 잘못된 코드 (중괄호 없음)
if (c == ' ')
    ++blank_cnt;
    printf("공백을 찾았습니다\n");
// printf는 항상 실행됨!
✅ 올바른 코드 (중괄호 사용)
if (c == ' ') {
    ++blank_cnt;
    printf("공백을 찾았습니다\n");
}
// 두 문장 모두 조건부 실행
⚠️ Python과 다른 점!
Python에서는 들여쓰기가 블록 범위를 결정하지만, C언어에서는 들여쓰기만으로는 부족합니다. 반드시 중괄호 { }로 블록 범위를 표시해야 합니다.

if-else 조건문

🔀 if-else statement 구조

문법 (Syntax)
if (조건식) statement1; // 참일 때 else statement2; // 거짓일 때
  • 조건식이 참(Non-zero) → statement1 실행
  • 조건식이 거짓(Zero) → statement2 실행
  • 두 경로 중 반드시 하나만 실행됨
조건식
True
↓
statement 1
False
↓
statement 2
↓
계속 실행

예시 코드

if-else 예시
C
// 최솟값 구하기
if (x < y)
    min = x;   // x < y 일 때
else
    min = y;   // x >= y 일 때

// 짝수/홀수 판별
if (number % 2 == 0) {
    printf("입력된 정수는 짝수입니다.\n");
} else {
    printf("입력된 정수는 홀수입니다.\n");
}

// 합격/불합격 (복합문)
if (score >= 80) {
    printf("합격입니다.\n");
    printf("장학금도 받을 수 있습니다.\n");
} else {
    printf("불합격입니다.\n");
    printf("다시 도전하세요.\n");
}
💡 조건 연산자 ?: 와의 관계
간단한 if-else 구조는 조건 연산자로 대체 표현 가능 (코드 간결화, 복합문 대체에는 부적절):
(score >= 80) ? printf("합격\n") : printf("불합격\n");
bonus = ((years > 30) ? 500 : 300);

if - else if - else 조건문

🪜 다중 조건 구조

문법 (Syntax)
if (조건1) statement1; else if (조건2) statement2; ... else statement_n;
  • 조건식을 차례로 검사하므로 이전 조건 검사 결과가 반영되어 있음
  • 마지막 else는 모든 조건이 거짓일 때 실행
조건1
True
stmt 1
False
조건2
T
stmt 2
F
stmt 3

성적 등급 예시

성적 등급 계산
C
if (score >= 90)
    grade = 'A';
else if (score >= 80)   // score는 90 미만이고, 80 이상일 때
    grade = 'B';
else if (score >= 70)   // score는 80 미만이고, 70 이상일 때
    grade = 'C';
else                    // 모든 조건이 거짓 (score가 70 미만)
    grade = 'F';
ℹ️ 이전 조건 결과가 반영됨
else if (score >= 80)은 위의 조건이 거짓(score < 90)임이 이미 보장된 상태에서 검사됨. 즉, 80 이상이고 90 미만인 경우를 자동으로 의미함.
05

if 조건문 사용 가이드라인

① C언어 True/False 정의에 따른 if 조건문 간략화

표준적인 방법 (더 명확한 표현) 간략한 표현법 설명
if (x != 0) ... if (x) ... x가 0이 아니면 (참)
if (x == 0) ... if (!x) ... x가 0이면 (거짓)

② 2개의 if 문 vs if-else 문

비효율적 — if 2개 사용
if (number % 2 == 0)
    printf("짝수입니다.\n");
if (number % 2 == 1)
    printf("홀수입니다.\n");
// 각각의 조건을 비교 → 비효율적
권장 — if-else 사용
if (number % 2 == 0)
    printf("짝수입니다.\n");
else
    printf("홀수입니다.\n");
// 비교 연산 한 번만 → 더 효율적

③ 중첩된 if 문 (Nested if Statement)

🪆 Nested if

복잡한 조건의 표현 → 논리 연산자(&&, ||)를 사용하여 조건들을 연결하는 게 효율적

중첩 if 사용
if (a == 1)
    if (b == 2)
        printf("***\n");
논리 연산자 활용 (권장)
if (a == 1 && b == 2)
    printf("***\n");
공백 문자 검사 — 논리 연산자 활용C
if (ch == ' ' || ch == '\n' || ch == '\t')
    white_space++;

④ Dangling else 문제 ⚠️ 주의!

⚠️ else는 가장 가까운 if와 짝을 이룸!

중첩된 if 문에서 else가 어느 if와 짝인지 주의해야 함.

코드 ① — else가 어느 if와 짝?
if (a == 1)
    if (b == 2)
        printf("***\n");
else          // 안쪽 if(b==2)와 짝!
    printf("###\n");
// a가 1이 아니면 아무것도 출력 안 됨
코드 ② — 의도가 명확한 버전
if (a == 1) {
    if (b == 2)
        printf("***\n");
} else {      // 바깥 if(a==1)와 짝
    printf("###\n");
}
// 항상 무언가 출력됨
⚠️ Dangling else
중첩된 if 문 구조가 프로그래머의 의도와 일치하는지 반드시 확인할 것. 중괄호를 사용하여 블록 범위를 명확히 하면 이런 문제를 예방할 수 있음.

⑤ Good Programming Tips

✅ 좋은 코딩 습관

  • 적절한 곳에 들여쓰기(indentation) 적용 — 코드 가독성 향상
  • 연관된 블록을 명확하게 하도록 중괄호 사용 — 항상 { }로 블록 감싸기
  • 중첩 if 문 구조가 우리 의도와 일치하는지 확인할 것
  • 복잡한 중첩 조건은 논리 연산자(&&, ||)로 단순화

switch 문 (switch Statement)

🔧 switch statement 구조

if-else if-...-else 구조를 대신해서 사용 가능. 하나의 변수/수식을 여러 값과 비교할 때 편리.

문법 (Syntax)
switch (control_expr) { case label1: statement; break; case label2: statement; break; default: statement; break; }

LAB: switchCntChars.c LAB

switchCntChars.c
C
switch (c) {
    case 'a':
        ++a_cnt;
        break;
    case 'b':               // 'b'이거나 'B'이거나
    case 'B':               // → break 없으면 다음 레이블로 fall through!
        ++b_cnt;
        break;
    default:
        ++other_cnt;
        // default에서 break 생략 가능 (마지막이므로)
}

fall-through 동작 이해

⚠️ fall-through (폴스루)

break 문이 없으면 해당 case를 실행 후 다음 case로 계속 실행됨 (fall through)

의도적 fall-through (유용)
case 'b': // 'b'와 'B' 모두 case 'B': // 같은 동작 ++b_cnt; break;

여러 값에 동일 동작 → 활용!

실수로 break 빠뜨리면
case 1: do_something(); // break 없음! case 2: // 여기도 실행됨 do_other();

오동작 버그 발생 주의!

switch 문 사용시 주의사항

📋 Good Practice with switch-case

  • switch 문에서 검사할 변수가 적절한 값으로 초기화되었는지 꼭 확인
  • case와 break를 먼저 적절한 위치에 써 놓고 시작하기
  • 꼭 필요한 경우가 아니라면 여러 개의 case를 하나로 묶는 코드는 피할 것
  • default 문을 꼭 써서 예상치 못한 입력 값에 대처할 수 있도록 준비하기
  • case 절에서 복합문 사용시 if 조건문과 달리 블록 범위 표시를 위한 중괄호 필요 없음
⚠️ case label은 정수형 상수만 가능!
case 문에서 검사할 내용(label)은 정수형 상수(문자 상수 포함)만 가능합니다.
case 레이블 종류가능 여부이유
case x:❌ 불가변수는 사용할 수 없다
case (x+2):❌ 불가변수가 들어간 수식 불가
case 0.001:❌ 불가실수는 사용할 수 없다
case "001":❌ 불가문자열은 사용할 수 없다
case 'a':✅ 가능문자 상수는 정수형 데이터이므로
case 42:✅ 가능정수 상수 사용 가능
07

switch 문과 if-else 조건문의 관계

ℹ️ 언제 switch를 쓰고 언제 if-else를 쓸까?
switch문은 if-else if-...-else 구조를 대신할 수 있지만, 모든 경우에 상호 교체가 가능한 것은 아닙니다.

예시 ① — 구분되는 조건이 많고 각각 실행문이 다를 때 switch 유리

if-else if 방식
if (number == 0)
    printf("없음\n");
else if (number == 1)
    printf("하나\n");
else if (number == 2)
    printf("둘\n");
else
    printf("많음\n");
switch 방식 (더 명확)
switch (number) {
    case 0: printf("없음\n"); break;
    case 1: printf("하나\n"); break;
    case 2: printf("둘\n");  break;
    default: printf("많음\n"); break;
}

예시 ② — 여러 개의 조건에 대한 실행문이 동일하고 범위로 조건 표현이 유리할 때 if-else 유리

if-else 방식 (간결)
if (score >= 90 && score <= 100)
    printf("A학점입니다.\n");
switch 방식 (불편)
switch(score) {
    case 100: case 99: case 98:
    // ... case 91: case 90:
        printf("A학점입니다.\n");
        break;
    // ...
}

📊 switch vs if-else 비교 요약

비교 항목 switch if-else
조건 표현 정수형 상수와의 동등 비교만 가능 범위, 복잡한 조건 모두 가능
가독성 많은 이산값 비교 시 더 명확 범위 조건 시 더 간결
주의사항 break 빠뜨리면 fall-through 발생 Dangling else, 중괄호 생략 주의
범위 조건 ❌ 모든 값 열거해야 함 ✅ 표현 가능
Q

Quiz

Q1 다음 코드의 실행 결과는? (int x = 5;) 
if (x < 10)
    printf("10보다 작음\n");
else if (x == 5)
    printf("5와 같음\n");
else
    printf("5와 같지 않음\n");
✅ ① "10보다 작음" 출력
x=5 이므로 첫 번째 조건 x < 10이 참 → 즉시 해당 블록 실행 후 전체 if-else if-else 구조를 빠져나감. 두 번째 조건 x == 5는 검사하지 않음. if-else if-else는 하나의 조건만 실행됨!
Q2 다음 코드에서 잘못된 부분을 찾아 고치시오.
(a) 청소년 나이 검사 코드 
if (0 < age <= 18)
    printf("청소년\n");
✅ 항상 참이 되는 버그!
C언어는 수학의 연쇄 부등식을 지원하지 않음.
0 < age <= 18은 (0 < age) <= 18로 해석됨.
(0 < age)의 결과는 0 또는 1 → 이 값은 항상 <= 18이 참!

올바른 코드: if (age > 0 && age <= 18)
Q3 다음 코드에서 잘못된 부분을 찾아 고치시오.
(b) x가 0인지 확인하는 코드 
if (x = 0)
    printf("x는 0이다.\n");
✅ 대입 연산자 vs 동치 연산자 혼동 버그!
if (x = 0)에서 =는 대입 연산자 → x에 0을 대입하고 결과값 0(거짓)을 조건식으로 사용. 결과: x는 항상 0이 되고, printf는 절대 실행되지 않음.

올바른 코드: if (x == 0)  ← 동치 연산자 == 사용
Q4 다음 코드에서 else는 어느 if와 짝을 이루는가? (x=5, y=3일 때 출력 결과는?) 
int x = 5, y = 3;
if (x > 10)
    if (y > 2)
        printf("A\n");
else
    printf("B\n");
✅ 아무것도 출력되지 않음 — Dangling else!
else는 가장 가까운 if인 if (y > 2)와 짝을 이룸.
x=5이므로 if (x > 10)이 거짓 → 안쪽 블록 전체(if(y>2)~else 포함) 건너뜀 → 아무것도 출력 안 됨.

만약 else를 바깥 if와 짝짓고 싶다면:
if (x > 10) { if (y > 2) printf("A\n"); } else printf("B\n");
Q5 switch 문에서 break를 모두 제거하면 어떻게 되는가? (c = 'a'일 때) 
switch (c) {
    case 'a': ++a_cnt;
    case 'b': ++b_cnt;
    default: ++other_cnt;
}
✅ a_cnt, b_cnt, other_cnt 모두 1씩 증가!
break가 없으면 매칭된 case부터 시작하여 switch 블록 끝까지 모든 case가 순차 실행됩니다 (fall-through).
c='a'이므로 case 'a'에서 시작 → break 없음 → case 'b' 실행 → break 없음 → default 실행.
